## D-034 | 2026-10-08 | MSG 추임새 뒤 뭉개진 낱말은 추임새 소리 뒷부분으로 · 말 없는 시범 앞 '다시 해볼게요'는 남김 · 다시 보기는 원본 장면 안 · 딴소리 조각은 남김
- **상태**: 채택
- **맥락**: round5 최종 판정 중간 결과와 정답(truth) 대조에서 원본마다 되풀이된 것: (1) 받아쓰기가 '아, 아깝다.'를 '아,'(1.2초) + '아깝다.'(다음 소리 앞 0.05초)로 적어, 추임새 정리가 '아깝다' 소리까지 잘라 실패 반응이 빠짐(S1·S3 모든 후보, 판정 '빠진 말') (2) S1 '다시 한번 해볼게요.' 뒤에 공 소리를 못 잡은 말 없는 시범이 바로 오는데 슬레이트 말로 뺌 (3) 다시 보기 원본 구간이 시범 뒤 원본 장면 바뀜(스튜디오)까지 이어져 '다시 보기 ▶'가 말하는 장면 위에 남음(판정 오류 2번) (4) 딴소리 조각('자, 공 좀 가져올게요', 1.3초)을 짧은 조각으로 보고 뺌(판정 '빠진 말').
- **결정**: (1) `align_to_sound`(`ALIGN_VER` 4): 추임새 바로 뒤 뭉개진 낱말이 추임새 소리 덩어리(0.6초 넘음)와 0.3초 넘게 떨어져 있으면 그 덩어리 뒷부분(앞 0.35초 남짓은 추임새)으로 옮김 (2) `_demo_call_ok`: 다음 말보다 공 소리(6초 안) 또는 말 없는 시범 시작(2초 안)이 먼저 오면 시범 예고 — editor.recommend 의 슬레이트 말과 clean_lines 의 쪼개진 슬레이트 말 모두 (3) `_replay_span`: 다시 보기 원본 구간을 공 차는 순간 앞뒤의 원본 장면 바뀜 안쪽으로(남는 길이 1초 넘을 때만) (4) `SLIVER_KEEP` 에 'aside'.
- **이유**: 모두 판정 모델이 실제 실수(빠진 말·엉뚱한 표시)로 적었고, 정답 대본으로도 '말한 문장'이 빠진 것. 규칙은 진짜 추임새('아' 하나·짧은 덩어리)·진짜 다시 찍기 신호(다음 말이 먼저)·짧은 혼잣말 조각(재미 순간 없음)은 그대로 잡음.
- **영향/제약**: 받아쓰기 맞춤 판이 4가 되어 MSG 를 처음 만들 때 단어 시각을 한 번 더 맞추고 신호(`msg_signals.json`)도 다시 만든다. 딴소리 조각을 남기면 1~2초 사이에 컷이 두 번 생길 수 있음(담백).

## D-033 | 2026-10-08 | MSG 정리할 말: 쉬었다 잇는 문장 머리('사실 이건')는 끊긴 말이 아님 · 쉼으로 쪼개진 '다시 해볼게요'도 시범 예고면 남김

- **결정**: `_fragment` 의 서술어·이음말 끝(`PRED_END`)에 '건'(것은)을 더함 · `_demo_calls`: clean_lines 가 '슬레이트 말'로 뺀 것 중 '다시 …'이고 다음 말보다 공 소리가 6초 안에 먼저 오면 남김(editor.recommend 의 슬레이트 말과 같은 규칙 · 앞의 '어,'는 그대로 뺌).
- **이유**: 두 규칙 모두 진짜 끊긴 말('오늘 진짜' …)·진짜 다시 찍기 신호는 그대로 잡고, 문장 머리·시범 예고만 풀어 줌. 슈팅 챌린지(S3) 후보 20개는 바뀐 규칙으로 다시 만들어도 편집이 같음(확인).
- **영향/제약**: 받아쓰기가 다른 꼴로 끊긴 문장 머리('그러니까 이게' 등)는 여전히 끊긴 말로 볼 수 있음 — 실제 촬영본으로 확인(I-039).

## D-032 | 2026-10-08 | MSG 배경음악은 말 밑에서도 들리게(말보다 약 21~23dB 작게) · 작은 제목은 같은 말 자막과 겹치지 않게
- **상태**: 채택
- **맥락**: round5 최종 판정을 시작하자 Claude 판정이 담백 후보마다 '배경음악이 말보다 약 30~32dB 작아 거의 안 들림'(편집본 측정 말-배경음악 중앙값 31.7dB · round3·4 도 25~33dB)과 '제목 슈팅 챌린지와 자막 오늘은 슈팅 챌린지예요가 한꺼번에 같은 말'을 가장 나쁜 점으로 적었다. 말할 때 줄이는 양(duck -13~-14dB)과 말 크기 기준(`dialogDb` 는 보정 전 원본 소리라 목소리 보정 뒤 말이 5~6dB 더 큼)이 겹친 탓이다.
- **결정**: 기본 스타일의 `sound.duck` -13~-14 → -7~-8dB, `bgmDb` -7~-10 → -5~-7dB(담백 -7 · 예능 -5 · 쇼츠 -6 · 다큐 -6) · 배운 값 범위 `BANDS` duck (-14, -6) · bgmDb (-10, -4). 개발 측정(보통 · 믹서 버스): 말할 때 말-배경음악 담백 23.4(S3)·21.6(S2) · 예능 21.0 · 쇼츠 하이텐션 19.6·18.9 · 다큐 22.3dB(예전 S3 담백 31.7). 작은 제목이 보이는 동안 본편 말 자막이 같은 말을 하면 그 자막 뒤로 4초 안에서 미루고(`_title_after_said` · `TITLE_SHIFT`), 첫 질문 장면 위 제목이면 그 말 전에 끝냄.
- **이유**: 말 밑 음악이 30dB 아래면 사실상 없는 것과 같아 '음악·소리' 스타일 부분이 후보마다 차이가 없다. 판정 관문(U5)은 15dB 넘게 작게라 여유가 있다.
- **버린 대안**: 말 크기 기준을 보정한 말로 바꾸기 — 신호 판(`SIG_VER`)·효과음 기준까지 바뀌어 범위가 커짐 / 제목을 지우기 — 담백·다큐의 작은 제목이 스타일 얼굴.
- **영향/제약**: 사용자가 편집실에서 '말할 때 배경음악 줄이기' 양을 바꾸면 그 값이 우선. 쇼츠 하이텐션형은 말 밑 음악이 가장 커서(약 19dB) 다른 원본에서 15dB 가까이 갈 수 있음 — 판정 U5 로 확인.

## D-031 | 2026-10-08 | MSG 재미 글자 층(정해 둔 문구 + 켤 때만 클로드가 씀) · 글자 양은 '재미' 부분 · 스타일마다 컷 리듬·인트로 구조 · 다시 보기 재시도는 구성을 지킴 · 배경음악 변주·내 배경음악

## D-001 | 2026-10-06 | 표준 라이브러리 HTTP 서버 + 단일 파일 HTML 화면 + pywebview 창 (프레임워크 없음)

- **맥락**: 비전문가 Windows 사용자가 설치·업데이트를 신경 쓰지 않고 쓸 로컬 앱이 필요하다. 개발은 1인 + AI다.

- **이유**: 설치는 pip뿐이고, 업데이트는 파일 교체로 끝난다. 사용자에게는 브라우저 탭이 아닌 "앱 창"으로 보인다 (v1.2.0부터).

- **영향/제약**: 긴 처리는 `start_job`(한 번에 하나) + `core.set_progress`로 하고, 화면은 `/api/state`를 폴링한다. 새 API는 `Handler`에 Host·Origin 검사 뒤에 둔다 (`ARCHITECTURE.md` 7절).
