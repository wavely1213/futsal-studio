소재 찾기

채널에서 반응이 좋았던 영상부터 보여드려요. 다시 쓸 영상을 골라 보관함에 담으세요.

처음이세요? 영상 한 편은 이렇게 이어져요
  1. 영상 넣기 · 여기서 채널 영상을 보관함에 담거나, 2 보관함의 [촬영 원본 넣기]로 찍은 영상을 넣어요
  2. 2 보관함 → [편집점 찾기] · 대사를 받아쓰고 1차 가편집(롱폼·쇼츠)까지 만들어요
  3. 3 편집점에서 대사·컷 후보를 훑어보고 4 편집실에서 다듬은 뒤 [내보내기]
  4. 5 썸네일 저장 → 7 올리기에서 제목·설명·챕터를 만들어 유튜브에 올려요
다운로드가 계속 실패하나요? 왼쪽 아래 업데이트 확인을 먼저 눌러 보세요. 그래도 안 되면 YouTube에 로그인해 둔 브라우저를 골라 다시 담아 보세요.
파이어폭스가 가장 잘 돼요. 엣지·웨일·크롬은 창을 모두 닫고(화면 오른쪽 아래 숨겨진 아이콘까지) 받아 주세요. 최신 크롬은 새 보안 기능 때문에 안 될 수 있어요.
아직 불러온 영상이 없어요"채널 불러오기"를 누르면 조회수 순으로 정리해 드려요.

편집실

열면 1차 가편집이 이미 세팅돼 있어요. 롱폼 가편집 1개와 쇼츠 편집본(추천 구간)이 자동으로 만들어져요.

편집할 수 있는 영상이 없어요보관함에서 영상을 고르고 "편집점 찾기"를 먼저 해 주세요.

스타일 배우기

따라 하고 싶은 유튜버 채널의 인기 영상을 '학습용 영상'에 담아 고르면, 그 채널의 공식(인트로 구성·장르·형식·자막 처리·재미 요소)을 판단하고 컷 리듬 같은 편집 습관까지 배워 "스타일"로 저장해요. 편집실의 자동 가편집이 그 스타일대로 잘라 줘요. 학습용 영상은 편집할 영상(보관함)과 따로 보관돼요.

썸네일

Google 설정 안내

처음 한 번 · 약 15분

유튜브에 바로 올리려면 내 Google 계정에 '풋살 스튜디오'라는 작은 앱 자리를 한 번 만들어야 해요. 돈은 들지 않아요. Google Cloud 화면은 PC 설정에 따라 한국어나 영어로 보여서, 버튼 이름을 두 가지로 적었어요 (영어 이름). 각 단계의 [열기]를 누르면 그 화면이 브라우저에 열려요. 결제 정보 입력·'무료 체험' (Free trial) 안내가 나와도 건너뛰면 돼요 (이 기능은 결제가 필요 없어요).

꼭 알아 두세요 · 1~8단계(약 15분)를 마치면 바로 올릴 수 있지만, 9단계 Google 감사를 통과하기 전에 올린 영상은 비공개로 잠겨서 나중에도 공개로 바꿀 수 없어요 (Google 규칙 · 비공개로 올려도 마찬가지). 감사는 신청서를 내면 Google이 검토해요 · 걸리는 기간은 Google도 정해 두지 않았어요. 그때까지는 시험용으로만 올리고, 공개할 영상은 지금처럼 키트를 복사해 스튜디오에서 올려 주세요.
1

Google Cloud에 로그인

✓
  • 풋살사관학교 채널을 관리하는 Google 계정으로 로그인해요. 채널이 브랜드 계정이면, 그 브랜드 계정을 관리하는 내 Gmail로 로그인하면 돼요.
  • 처음이면 약관 화면이 나와요 → 동의하고 [동의 및 계속하기] (Agree and continue)
화면 모습왼쪽 위에 'Google Cloud' 글자, 그 옆에 프로젝트를 고르는 칸이 있어요 (그림 준비 중)
2

새 프로젝트 만들기

✓

  • 다 만들면 위쪽 프로젝트 칸에 '풋살 스튜디오'가 골라져 있는지 봐요. 아니면 눌러서 골라요.
화면 모습'새 프로젝트' (New Project) 제목 아래 '프로젝트 이름' 칸과 파란 [만들기] 버튼 (그림 준비 중)

5

대상: 앱 게시하기 (추천)

✓
  1. 추천 · [앱 게시] (Publish app) → [확인] (Confirm) → 게시 상태가 '프로덕션 단계' (In production)가 돼요. 이러면 7일마다 연결이 끊기지 않아요. Google 확인(심사)을 받으라는 안내가 나와도 혼자 쓰는 개인용이라 받지 않아도 돼요 (사용자 100명 제한은 상관없어요). 계정을 연결할 때 'Google에서 확인하지 않은 앱' (Google hasn't verified this app) 화면이 나오면 [고급] (Advanced) → [풋살 스튜디오(으)로 이동(안전하지 않음)] (Go to 풋살 스튜디오 (unsafe))을 눌러요. 내가 만든 내 앱이라 괜찮아요.
  2. 또는 테스트 상태 그대로 둘 때: '테스트 사용자' (Test users) → [+ 사용자 추가] (+ Add users) → 내 Gmail을 넣고 [저장] (Save). 이때는 Google 규칙 때문에 7일마다 연결이 끊겨서 [다시 연결하기]를 눌러야 해요.

화면 모습'게시 상태' (Publishing status) 아래 '테스트 중' (Testing)과 [앱 게시] 버튼, 그 아래 '테스트 사용자' 목록 (그림 준비 중)

클라이언트 만들기 (데스크톱 앱)

✓

  • 받은 파일(client_secret_….json)은 비밀번호와 같아요. 다른 사람에게 보내지 마세요.

유튜브 계정 연결하기

✓ 연결됐어요
  1. 아래 [계정 연결하기]를 누르면 브라우저가 열려요.
  2. 계정 고르기에서 채널을 관리하는 내 Google 계정을 골라요. 그 뒤(또는 그 앞)에 채널·브랜드 계정을 고르는 화면이 나오면 풋살사관학교를 골라요 (Choose an account or brand account). 순서는 Google 화면에 따라 달라요.
  3. 'Google에서 확인하지 않은 앱' 화면이 나오면 [고급] → [풋살 스튜디오(으)로 이동(안전하지 않음)]

공개로 올리려면 꼭: YouTube API 감사 신청

✓ 통과
  • Google은 감사를 받지 않은 프로젝트(2020년 7월 뒤에 만든 프로젝트)로 올린 영상을 '비공개(잠김)'로 만들어요. 잠긴 영상은 나중에 공개로 바꿀 수 없어요 (다시 올려야 해요).
  • 아래 [신청서 열기]에서 'YouTube API 서비스 감사' (YouTube API Services - Audit and Quota Extension Form)를 내요. 묻는 칸이 여러 개예요 (프로젝트 번호, 쓰는 방법, 화면 설명 등) · '내 채널에 내 영상을 올리는 개인용 도구'라는 점을 중심으로 적어요. Google이 추가 자료를 물어볼 수 있어요.
  • 걸리는 기간은 Google도 정해 두지 않았어요 (문서에는 '가능한 한 빨리'만 있어요) · 통과를 약속하지도 않아요.
  • 통과 메일을 받기 전에 올린 영상은 비공개로 올려도 잠겨요 (시험용). 공개할 영상은 그때까지 키트를 복사해 스튜디오에서 올려 주세요. 통과 메일을 받으면 아래에 체크해요.

문제 해결

'액세스 차단됨: … Google 인증 절차를 완료하지 않았습니다' · 오류 403: access_denied

앱이 테스트 상태인데 테스트 사용자로 넣지 않은 계정이에요. 5단계에서 (a) [앱 게시]를 하거나, (b) 테스트 사용자에 내 Gmail을 넣어 주세요.

오류 400: redirect_uri_mismatch

클라이언트를 '웹 애플리케이션'으로 만들었어요. 6단계대로 데스크톱 앱으로 새로 만들고 7단계에서 새 JSON 파일을 넣어 주세요.

'YouTube Data API v3 has not been used in project …' · API를 켜지 않았어요

3단계에서 [사용]을 누르고 몇 분 기다린 뒤 다시 해 주세요. 위쪽에 고른 프로젝트가 '풋살 스튜디오'인지도 봐요.

'오늘 쓸 수 있는 유튜브 API 양을 다 썼어요'

유튜브 API는 하루에 쓸 수 있는 양이 정해져 있어요. 영상 올리기는 하루 100번, 썸네일·자막·재생목록·확인은 합쳐서 하루 10,000 단위예요(자막 하나 400). Google 기준 자정(한국 시간 오후 4시 · 겨울에는 5시)에 다시 채워져요. 그 뒤에 [이어 올리기]·[마저 하기]를 눌러 주세요.

7일마다 연결이 끊겨요

앱이 '테스트' 상태라서 그래요 (Google 규칙). 5단계 (a) [앱 게시]를 하면 더 끊기지 않아요. 끊겨도 [다시 연결하기]만 누르면 올리던 것은 [이어 올리기]로 이어져요.

오래 안 썼더니 연결이 안 돼요

6개월 넘게 쓰지 않으면 연결이 끊기고, 클라이언트가 지워질 수도 있어요. [다시 연결하기]가 안 되면 6·7단계를 다시 해 주세요.

연결을 완전히 끊고 싶어요

이 화면의 [연결 끊기]를 누르면 Google에도 연결을 끊어요. Google 계정의 '서드 파티 연결' 화면에서도 끊을 수 있어요.
