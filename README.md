# 풋살사관학교 스튜디오

채널 영상 받기 → 받아쓰기·편집점 분석 → 러프컷까지 한 화면에서 합니다.
본인 PC에서 실행하는 프로그램이고, 화면은 브라우저에 열립니다(인터넷에 공개되지 않음).

## 설치와 실행

| PC | 처음 한 번 | 그다음부터 |
|---|---|---|
| Windows | `시작하기 (Windows).bat` 더블클릭 | 바탕화면의 **풋살사관학교 스튜디오** 아이콘 |
| Mac | `시작하기 (Mac).command` 더블클릭 (처음엔 우클릭 → 열기) | 응용 프로그램(`~/Applications`)의 **풋살사관학교 스튜디오** |

- 브라우저가 아니라 **전용 앱 창**으로 열립니다. 검은 창은 처음 설치할 때만 보입니다.
- **받은 압축 파일은 먼저 풀어 주세요** (오른쪽 클릭 → '압축 풀기'·'모두 압축 풀기', `C:\풋살스튜디오` 처럼 짧은 곳). 압축 파일 안에서 바로 더블클릭하면 그렇게 하라고 알려 주고 멈춰요.
- Python 3.10~3.14 (64비트)를 씁니다. 여러 버전이 있으면 3.13 → 3.12 → 3.11 → 3.14 → 3.10 순서로 골라요. 맞는 Python이 없으면 **Python 3.14 설치 파일(python-3.14.8-amd64.exe)이 바로 받아져요** — 실행해서 첫 화면 아래 "Add python.exe to PATH" 를 체크하고 "Install Now" 를 누른 뒤 다시 더블클릭하세요. Python 3.15 는 아직 받아쓰기 구성요소가 없어 쓸 수 없어요 (지우지 않아도 되고 3.14 를 함께 설치하면 돼요). python.org 첫 화면의 새 **Python install manager**(Python 설치 관리자)로 설치한 PC는 bat 이 3.14 를 알아서 설치해요.
- 구성요소 설치가 실패하면 까닭을 한국어 한 줄로 알려 줘요 (인터넷·보안 프로그램·저장 공간·파일 사용 중·Python 버전). 자세한 기록은 `%TEMP%\futsal-studio-pip.log` 에 남아요.
- 첫 실행은 구성요소 설치로 몇 분 걸립니다. ffmpeg는 자동으로 포함됩니다. 받아쓰기·누끼에 필요한 Microsoft Visual C++ 구성요소가 없으면 함께 설치해요 (관리자 확인 창이 뜨면 '예').
- 구성요소 폴더(`.venv`)를 만든 Python 을 지웠거나 더 새 Python(3.11 이상)을 설치했다면, `시작하기 (Windows).bat` 을 다시 실행하면 `.venv` 를 `.venv.old` 로 옮겨 두고 새로 만들어요. 앱 폴더 경로가 너무 길면(윈도우 260자 제한) `C:\풋살스튜디오` 처럼 짧은 곳으로 옮기라고 알려 줘요.
- 앱 창을 닫으면 프로그램도 종료됩니다. 작업 중이면 한 번 물어보고, 닫으면 그 작업은 멈춰요 (알고 닫은 것이라 다음에 켤 때 '갑자기 꺼졌어요' 알림은 뜨지 않아요).
- 편집점 찾기·묶기 중에 프로그램이 갑자기 꺼지면(메모리가 모자랄 때 등) 다음에 켤 때 **보관함**으로 열리고, 어느 영상이었는지와 **빠르게로 다시 하기** · **정확하게로 다시 하기**(빠르게였으면 **다시 하기**) 버튼이 있는 카드가 떠요. '정확하게' 받아쓰기 중에 꺼졌다면 메모리를 3분의 1쯤만 쓰는 '빠르게'로 다시 해 보세요. 카드를 닫지 않고 다른 화면에 다녀와도 다시 보관함으로 끌고 가지 않아요 (카드는 보관함에 남아 있어요).
- 완성본·묶은 영상을 백신·OneDrive 가 잡고 있어서 제자리로 못 옮기면, 결과 파일만 남겨 두었다가(중간 파일은 지워서 공간을 차지하지 않아요) **다음에 앱을 켤 때** 완성본 폴더·보관함으로 옮겨 드려요.
- 작업 폴더를 옮기려면 앱 폴더의 `config.json` 에서 `"workspace"` 를 고쳐요 (`"D:\풋살작업"` 처럼 써도 돼요). 잘못 고쳤거나 그 폴더(외장 드라이브 등)를 쓸 수 없으면 기본 작업 폴더로 열고 알려 줘요.
- 문제가 생기면 작업 폴더의 `studio.log` 와 (있으면) `studio-error.log` 를 보내주세요. `studio.log` 에는 작업 기록과 오류가 난 곳(한 줄씩), '지난번에 갑자기 꺼졌는지'가 들어 있고, `studio-error.log` 에는 같은 오류의 자세한 추적과 프로그램이 통째로 멈춘 위치가 들어 있어요. 휴대폰 연결 주소·알림 주제 같은 비밀은 두 파일 모두 '…'로 지워서 남겨요. `studio.log` 가 커지면(2MB) `studio.old.log` 로 하나만 남기고 새로 써요 — 같이 보내 주시면 더 좋아요. 왼쪽 아래 **작업 폴더**를 누르면 그 폴더가 열리고, 실패 카드의 **studio.log 위치 열기**를 누르면 그 파일을 골라 보여 줘요.
- 작업이 실패하면 그 작업을 시킨 화면 위쪽에 빨간 줄이 있는 **실패 카드**가 남아요. 쉬운 말로 까닭을 알려 주고, 할 일 버튼(**다시 하기** · **이 브라우저로 다시 받기** · **로그인 정보 없이 다시 하기** · **업데이트 확인** · **폴더 열기** · **주소 다시 넣기** · **쇼츠로(긴 영상으로) 다시 불러오기** · **studio.log 위치 열기**)을 눌러 그 자리에서 해결할 수 있어요. 다 보면 ✕ 로 닫아요. 편집실의 내보내기가 실패해도 닫을 때까지 남는 카드로 알려 줘요(**다시 내보내기** · **완성본 폴더 열기**). 휴대폰에서 시킨 작업이 실패하면 휴대폰의 '마지막 작업' 칸에도 같은 쉬운 한 줄이 보여요.

## 화면 구성

1. **소재 찾기** — 채널 불러오기(조회수 순) → 썸네일을 눌러 고르기 → 보관함에 담기
처음 켜서 보관함이 비어 있으면 1단계 위에 **시작 안내**(영상 넣기 → 편집점 찾기 → 편집점·편집실 → 썸네일 → 올리기)가 보여요. **다시 안 보기**로 닫을 수 있어요.

2. **보관함** — 촬영 원본은 "촬영 원본 넣기"로 연 폴더에 넣기 → 체크 → 편집점 찾기
   - 받아쓰기는 **정확하게 / 빠르게** 중에서 골라요. 처음엔 이 PC 사양에 맞게 골라 둬요 (메모리 8GB 이하이거나 4코어 이하면 '빠르게' — 60분 영상이면 약 16분 · 메모리 약 0.8GB, '정확하게'는 약 48분 · 2GB). 바꾸면 기억하고, 버튼 아래에 고른 영상의 예상 시간·메모리를 보여 줘요 ('빠르게'를 골라 둔 까닭도 · 영상을 아주 많이 고르면 처음엔 '약'으로 어림해요).
   - 편집점 찾기·묶기가 끝나면 **3 편집점**에서 방금 찾은 영상의 대사·컷 후보를 보여 주고, **편집실에서 열기**로 그 영상이 열려요.
   - 줄마다 **이름 바꾸기**가 있어요. 영상 이름을 바꾸면 받아쓰기·편집본·썸네일 디자인(AI 추천 썸네일이 따 둔 누끼·장면 점수 포함)도 함께 옮겨요 (탐색기에서 바꾸면 이어지지 않아요). 클로드가 만든 썸네일 문구는 제목을 보고 만든 것이라, 제목이 바뀌면 썸네일 편집기의 **🤖 클로드로 더 만들기**로 새 제목 문구를 받아요. 탐색기에서 이미 바꿨다면 그 줄에 '예전 이름의 받아쓰기·편집본이 있어요'가 뜨고 **예전 작업 이어 붙이기**로 다시 이을 수 있어요 (크기·날짜·길이가 같은 파일일 때만). 완성본 폴더에 이미 내보낸 파일 이름은 그대로라서, 그런 파일이 있으면 바꾸기 전에 알려 줘요 (4·7단계에는 다시 내보낼 때까지 '아직 안 내보냄'으로 보여요). 이름을 바꾸기 전에 열어 둔 편집실·썸네일 창은 저장(썸네일 그림·A/B 저장 포함)하지 않고 '스튜디오에서 다시 열어 주세요'라고 알려 줘요.
   - 큰 촬영본을 옮기는 동안에는 **복사 중…** 표시가 붙고 고를 수 없어요. 복사가 끝나면(크기가 몇 초 동안 그대로면) 저절로 사라져요 — 덜 들어온 영상으로 편집점을 찾지 않게 해요.
   - 편집점을 찾은 뒤 영상 파일이 바뀌었으면(덜 복사된 채로 찾았을 때 등) **파일이 바뀌었어요**가 붙어요. 그 줄의 **편집점 다시 찾기**를 눌러 주세요 (내 편집본은 그대로예요).
   - 캠코더 `.MTS`·`.AVI`·`.WMV` 같은 형식은 **바로 못 써요** 줄로 보여요. 그 줄의 **MP4로 바꾸기**를 누르면 편집할 수 있는 MP4로 바꿔 보관함에 넣어 줘요. 원본은 보관함 폴더 안 `바꾸기 전 원본` 폴더로 옮겨 그대로 둬요 (MP4·MOV·M4V·MKV·WEBM 는 바로 쓸 수 있어요).
   - 여러 영상의 편집점을 찾다가 깨진 영상이 있으면 그 영상만 건너뛰고 나머지는 끝내요. 실패 카드에 어느 영상인지 나오고, **다시 하기**는 그 영상만 다시 해요.
   - 영상마다 **풋살사관학교 / 다른 채널(채널 이름) / 내 촬영본** 표시가 붙고, 위쪽 칸으로 골라 볼 수 있어요 (아래 '영상 출처 구분').
   - 아래 **용어 사전**에 풋살 용어·이름(피벗·픽소·최경진 감독…)을 넣어 두면 받아쓰기가 더 정확해져요. 자꾸 틀리게 나오는 말은 '틀리게 나온 말 → 바른 말'로 넣으면 고쳐 줘요 (예: 피버 → 피벗). **저장**을 누르면 다음 편집점 찾기부터 적용돼요.
   - '정확하게'로 받아쓰면 앞 문장에 기대지 않고 구간마다 새로 들어요 — 같은 문장을 한 번 더 쓰거나 끝에 하지 않은 말('다음 영상에서 만나요')을 지어내지 않아요. 대신 마침표가 덜 찍혀 한 줄이 길어질 수 있는데, 자막은 단어 시각으로 한 줄씩, 올리기 키트는 문장으로 나눠 써요. '빠르게'는 예전처럼 받아써요(그쪽이 더 정확해서요).
3. **편집점** — 대사·컷 후보·하이라이트를 시간순으로 확인 → "Claude에게 보낼 내용 복사"
4. **러프컷** — Claude가 준 컷 목록 붙여넣기 → 미리보기 확인 → 쇼츠(세로) 또는 롱폼(가로) 영상 + 프리미어·다빈치용 EDL

작업 파일은 사용자 폴더의 `풋살사관학교_작업` (Windows: `C:\Users\이름\풋살사관학교_작업`, Mac: `~/풋살사관학교_작업`)에 저장됩니다. 업데이트해도 지워지지 않습니다.

## 편집실 (v1.7.0 · 프리미어식 편집기)

보관함에서 **편집실 열기** → 프리미어 프로 같은 화면에서 편집합니다. 단축키는 프리미어와 같아요 (화면에서 ⌨).

- **트랙**: 영상 V1~V3 · 소리 A1~A3 (추가 가능). 트랙마다 잠금·음소거·솔로·숨기기·높이·대상 지정
- **가져오기**: 다른 영상·음악·이미지를 버튼/끌어다 놓기/보관함에서. 소스 모니터에서 I/O 표시 후 삽입( , ) · 덮어쓰기( . ), 정지 화면, 마커(M)
- **도구**: V 선택 · A 앞쪽 트랙 선택 · B 잔물결 · N 롤 · R 속도 늘이기 · C 자르기 · Y 슬립 · U 슬라이드 · H 손 · Z 확대
- **편집**: Ctrl+K 자르기, Shift+Delete 잔물결 삭제, Q/W 잔물결 다듬기, ; 들어내기 · ' 추출, S 스냅, Alt+끌기 복제, Ctrl+C/V, 속성 붙여넣기
- **효과 컨트롤**: 위치·크기·회전·불투명도·볼륨 키프레임(직선/부드럽게), 볼륨 고무줄
- **장면 전환**: 디졸브 · 검정/흰색 페이드 · 닦아내기 · 밀어내기 · 소리 크로스페이드 (Ctrl+D)
- **속도**: 0.25~4배, 거꾸로 재생 (Ctrl+R) · **색**: 노출·대비·채도·색온도 등 간단 보정
- **소리**: 클립 게인·페이드·오디오 믹서와 레벨 미터, 말할 때 배경음 자동 줄이기, 목소리 보정, 소리 크기 맞추기(LUFS)
- **그래픽**: 제목, 하단 이름 자막 · 구독 버튼 · 강조 팝 텍스트 등 프리셋
- **전술 그림** (왼쪽 **그래픽** 탭 → 전술 그림): 영상 위에 **형광 화살표 · 곡선 화살표 · 패스 길(흐르는 점선) · 발밑 원 · 스포트라이트(선수만 밝게) · 선수 이름표**를 넣어요. 누르면 재생 위치에 들어가고, 화면의 **흰 점**을 끌어 자리를(노란 점은 원 크기), 점선 상자를 끌면 통째로 옮겨요. 오른쪽에서 색(하늘 네온·형광 연두·노랑·빨강·분홍·흰색)·두께·크기·이름표 글자·**그려지는 시간**(0이면 바로 나타나요)·빛 번짐을 바꿔요. 타임라인 G 줄(도형 줄)에서 끌어 옮기거나 끝을 늘려요. 끝나기 전 0.25초 동안 부드럽게 사라져요

- **추천·자동 편집 → 전체 영상 군더더기 정리 · 원본 전체로 되돌리기**: 지금 편집본의 원본 클립에서만 군더더기를 빼거나 잘라 낸 원본을 제자리에 다시 넣어요. 쇼츠는 그 쇼츠 구간 안에서만 바뀌고 쇼츠(세로) 그대로예요. 클립마다 확대·빠르기·색은 그대로이고, 제목·강조 글씨·표시·위 트랙은 같은 장면에 맞춰 함께 옮겨요 (말이 잘려 나간 강조 글씨는 빠져요). 바뀔 곳이 없으면 그렇게 알려 줘요 · Ctrl+Z 로 되돌려요

## 썸네일 (v1.6.0 · 포토샵식 편집기)

스튜디오의 **썸네일** 메뉴, 또는 편집실 위쪽 **썸네일 만들기**.

### ✨ AI 추천 썸네일 6개

'자동' 탭 맨 위의 **✨ AI 추천 썸네일 6개**를 누르면 장면·선수·공·표정을 찾고, 주인공 누끼를 따고, 제목 문구를 만든 뒤 잘 되는 풋살 레슨 채널처럼 6개를 만들어요 (처음 한 번 1~2분, 그다음은 몇 초).

- **레퍼런스형 디자인**: 전술 해설 두 가지(발밑 원·네온 화살표·'공간' 칩) · 강좌 시리즈(누끼 + 큰 제목) · 인물 + 오른쪽 제목 · 질문 훅 · 반전 O/X · 리액션 클로즈업 · 상자 제목. 쇼츠는 9:16 전용 디자인 7가지(전술·레터박스·누끼 크게·위 제목 + 아래 누끼·질문 훅·얼굴 + 아래 제목·상자 제목)
- **서로 다른 6개**: 디자인·장면·문구가 겹치지 않게 고르고, 휴대폰 목록 크기에서 안 읽히거나 재생 시간·쇼츠 버튼 자리에 걸리면 빼요. 카드마다 점수와 이유가 보여요
- **다시 추천** · **문구 후보 고르기**(직접 쓴 문구, 🤖 내 클로드 계정으로 더 만들기) · **장면 고르기**
- **편집하기**: 추천이 새 디자인으로 열리고 글자·누끼·전술 그래픽이 모두 따로 고쳐져요 (화살표 점을 끌어서 휘기)
- **전술 그래픽** 메뉴: 곡선 화살표 · 패스 점선 · 발밑 원 · 스포트라이트 · X · 번호/칩 · 반짝이 · 손그림 화살표 · '자동 배치'
- **스티커**(이모지 38개) · **브랜드 키트**(채널 로고·색·글꼴·시리즈 이름 → 추천에 바로 반영) · **자동 보정**(밝기·색감·선명하게)
- **검수**: 휴대폰 목록 크기 미리보기(롱폼 168px · 쇼츠 110px), 작게 봤을 때 읽히는 글자, 🤖 클로드에게 평가받기(선택)
- **A/B 묶음 저장**: 고른 2~6장을 `영상이름_썸네일_A.jpg`… 와 한눈에 비교하는 `모바일 비교.jpg` 로 완성본 폴더에
- **이긴 썸네일 적기**: 유튜브 스튜디오 '테스트 및 비교'가 끝나면, 같은 영상의 썸네일 화면 AI 추천 상자에 있는 A/B 줄에서 **이긴 썸네일(A·B·C…)을 한 번** 눌러 주세요. 다음 추천부터 우리 채널에서 이긴 디자인·문구 틀에 점수를 더 줘요. 잘못 눌렀으면 같은 버튼을 다시 누르면 지워져요
- **썸네일 스타일**: AI 추천 상자 위 **썸네일 스타일**에서 배운 스타일을 고르면 그 채널 썸네일 버릇(글자 색 두 개·글자 위치·크기·테두리·배경 밝기·누끼)대로 만들어요. 예) 쌈바형은 어두운 배경 + 큰 글자(강조 낱말은 노랑), lcs 같은 토크형은 밝은 배경 + 위 줄 흰 글자·아래 줄 노란 글자 + 두꺼운 테두리. 강조 낱말은 어떤 스타일이든 강조색으로 남아요. 고르지 않으면 늘 기본 모양이에요. A/B 에서 이긴 기록이 있으면 **우리 채널 (A/B 이긴 것)** 도 고를 수 있어요. 브랜드 키트에서 직접 바꾼 색이 있으면 그 색이 먼저예요
- 선수·공 찾기 모델(약 3.6MB)은 처음 한 번 내려받아요. 인터넷이 안 되면 얼굴·선명도만으로 골라요

- **롱폼 / 쇼츠 따로**: 롱폼은 1280×720(16:9), 쇼츠는 1080×1920(9:16) 캔버스로 만들어요. 자동 제작도 형식별 템플릿(롱폼 7종 · 쇼츠 5종)이 따로 있어요.
- **영상에 박힌 옛 자막 가리기**: 장면 아래쪽을 잘라 배경에 옛 자막이 안 보이게 (이미지 속성 › 원본 자르기에서 위·아래·좌우 조절)
- **얼굴·표정으로 장면 고르기**: 얼굴이 크고 또렷하게 웃거나 놀란 장면을 먼저 골라 자동 제작에 써요 (하이라이트·대사 핵심어 순간도 살펴보고, 고른 장면 앞뒤 0.4초 안에서 표정이 가장 좋은 순간으로). 영상 장면 줄에 😆 웃음 · 😮 놀람 · 얼굴 크기(%) 표시, **시간 순 / 표정 좋은 순** 정렬. 얼굴·표정 모델(ONNX 모델 모음, 약 36MB)은 처음 한 번 내려받고, 인터넷이 안 되면 예전 방식(선명도·밝기)으로 골라요
- **글자별 편집**: 한 글자 레이어 안에서 고른 글자만 색·크기·글꼴·테두리 바꾸기 (글자칸이나 글자 칩을 드래그해서 고르기), **문자 패널** 창
- **레이어 스타일 창** (레이어 두 번 클릭): 혼합 옵션·획·드롭 섀도·3D 입체(돌출)·외부 광선·색상 오버레이·레이어 마스크(한쪽으로 서서히 사라지기)·그라데이션·글자 뒤 상자·스타일 프리셋 12종
- **변형**: 8방향 손잡이, Ctrl+T 자유 변형, Ctrl+위/아래 손잡이로 기울이기, 끄는 동안 W·H(px)·%·각도·기울기 수치 표시, X·Y·W·H·각도 숫자 입력(이름을 좌우로 끌어 미세 조절), 스마트 안내선(캔버스·다른 레이어에 붙음)
- **레이어 패널**: 끌어서 순서 바꾸기, Shift/Ctrl+클릭 여러 개, 이름 두 번 클릭 → 이름 바꾸기
- 복사·붙여넣기(이미지 붙여넣기·끌어다 놓기 포함), 전체 선택, 맞춤·간격 맞추기, 오른쪽 클릭 메뉴(겹친 레이어 고르기), 확대·축소·손 도구, 스포이드, 혼합 모드 15종, 작업 내역

## 스타일 배우기 (v1.7.0~)

잘 나가는 유튜버의 편집 스타일을 배워서 자동 가편집에 그대로 써요. (기본은 AI 사용료 없음 · 내 PC에서 분석)

1. **스타일 배우기** → **학습용 영상**의 **채널 추가**를 누르고 따라 하고 싶은 채널 주소(예: `https://www.youtube.com/@채널이름`, `@채널이름`)를 넣거나 **추천 채널**에서 골라요 → 긴 영상/쇼츠, 몇 개(기본 인기 5개)를 고르고 **인기 영상 받기**
   - '받은 뒤 채널 이름 스타일로 배우기'가 켜져 있으면 다 받은 뒤 바로 **"채널이름 스타일"**(예: 슛포러브 스타일)을 배워요. 같은 이름의 스타일이 있으면 예전에 배운 영상까지 함께 다시 배워요.
   - **방향으로 한 번에 담기**: 채널 방향 조사에서 고른 방향 A(레슨 + 예능 MSG형)·B(챌린지·대결형)·C(쇼츠 집중형)의 추천 영상을 한 번에 받아요 (채널마다 스타일을 배워요).
2. 이미 받은 학습용 영상은 목록에서 골라(채널 칸을 누르면 그 채널만 · **이 채널 영상 모두 고르기**) 이름을 붙여 **스타일 배우기**를 눌러도 돼요. 편집용 보관함의 영상으로 배우려면 **보관함 영상도 보기**를 켜요.
3. 배운 스타일 카드에는 그 채널의 **공식**을 PD처럼 판단한 **영상 기획 분석**이 보여요
   - **인트로**: 예) 결과 장면을 먼저 보여 주는 티저형 훅 → 타이틀 → 본론 (인사 없음, 10초 이내)
   - 맨 위 굵은 글씨는 그 채널의 공식을 한 문장으로 말해요. 예) 이 채널은 결과 장면을 먼저 보여 주며 시작해 2~3인 대결로 끌고 가고, 슬로모션 리플레이·효과음으로 재미를 만드는 축구 예능 챌린지 채널이에요.
   - **장르**: 예) 축구 예능 챌린지 · **형식**: 예) 2~3인 대결 · 현장 리액션
   - **자막**: 예) 말 자막보다 예능 자막 위주, 핵심 단어를 노랑·빨강 큰 글씨로 강조, 속마음 자막 자주
   - **재미 요소**: 예) 결정적 장면 슬로모션 리플레이, 리액션 클로즈업 줌, 효과음
   - 줄마다 **확실해요 / 아마도 / 어림** 표시가 붙어요. 왜 그렇게 봤는지는 **근거 보기**를 펼치면 예시 1~2개가 나와요.
   - **우리 영상에 적용하면**: '가편집에 반영돼요' 표시가 붙은 것(티저형 인트로: 말이 적고 소리가 큰 시범 장면을 맨 앞에, 기술 이름·핵심 단어 강조 자막)은 스타일로 자동 편집할 때 저절로 들어가요. 배운 영상들끼리 판단이 갈리면 넣지 않고 '직접 해 보세요'로 보여 줘요. 핵심 단어 강조 글씨는 그 장면 얼굴을 가리지 않게 머리 위·옆·아래 빈자리에 놓여요.
   - 클로드 대답을 붙여 넣는 동안 스타일 배우기나 클로드 판단이 돌고 있으면, 끝난 뒤에 [저장]을 다시 눌러 주세요.
   - 컷 길이·확대 컷·말 사이 공백·자막 위치와 색·소리 크기·말 빠르기 같은 숫자는 **구조 수치 (편집 엔진용)** 안에 접혀 있어요.
   - 쇼츠와 긴 영상을 섞어 배우면 카드에 '배운 영상 N개 — 긴 영상 N개와 쇼츠 M개를 따로 배웠어요'가 나오고(위 기획 분석은 긴 영상 것), 롱폼 가편집엔 긴 영상의 컷 리듬·확대·자막을, 쇼츠 가편집엔 쇼츠의 값을 써요 (구조 수치도 형식마다 따로 보여요). 예전에 섞어 배운 스타일도 다시 배우지 않고 그대로 나눠 써요.
   - 예전에 배운 스타일은 **다시 배우기**를 누르면(같은 영상이 보관함이나 학습용 영상에 있을 때) 기획 분석이 생겨요.
   - **썸네일 버릇**: 배운 영상과 그 채널 인기 영상 12개의 유튜브 썸네일을 살펴보고 강조색 2개·큰 글자 줄 수·글자 높이·글자 위치(위/아래)·테두리·얼굴 크기·배경 밝기·채도·누끼를 보여 줘요 (배운 썸네일 몇 장도 함께). 스타일을 배우면 이어서 저절로 해요 (영상은 받지 않고 썸네일 그림만 · 인터넷 필요). 예전에 배운 스타일은 **썸네일 버릇 배우기**를 눌러요. **썸네일에 이 스타일 쓰기**를 누르면 썸네일 화면의 자동 후보·AI 추천이 그 버릇을 따라요 (누르지 않으면 버릇을 배워도 썸네일은 기본 모양 그대로예요). 어두운 배경 위 글자는 테두리를 잴 수 없어서 '잴 수 없음'으로 보여요. 글자·얼굴 값은 화면 글자·얼굴 모델이 받아져 있을 때만 나와요.
   - 처음 배울 때 화면 글자·소리를 알아듣는 모델(약 35MB)을 한 번 받아요. 못 받으면 '어림'으로 판단해요.
4. **편집실**에서 **스타일로 자동 편집**을 고르면 그 스타일대로 새 가편집 시퀀스를 만들어요 (내가 만든 시퀀스는 그대로 둬요)

### 기본 스타일 · 스타일 섞기 (MSG 자동 편집용)
스타일 배우기 화면의 **MSG 자동 편집 스타일**에서 기본 스타일 4개를 보고, **스타일 섞기**로 인트로·컷 리듬·자막·재미(MSG)·음악·소리를 부분마다 다른 스타일에서 골라 '풋살사관학교 스타일(초안)'처럼 저장해요. 정해진 스타일이 아니니 후보를 비교하며 계속 바꿔 보세요 ('최근 바꾼 것'에 남아요). 섞은 스타일은 배운 스타일 목록과 따로 저장돼요 (`styles/섞기/`). 섞은 스타일이 여러 개면 위 선택 칸에서 고른 것이 편집실 '좋아요'가 담기는 곳이 되고, 저장한 'MSG 양'은 그 스타일을 고를 때 미리 골라져요. 글자 양(1분 속마음·효과 수)은 '재미(MSG)' 부분을 따라가요.

### 학습용 영상 (스타일 배우기 전용 · v2.0.0~)

스타일을 배우려고 받은 다른 채널 영상은 **편집할 영상(보관함)과 따로** 둬요. 보관함·편집점·편집실·썸네일·올리기 목록에는 나오지 않아요.

- 채널마다 색이 다른 칸(예: 도블락 2 · 슛포러브 3)으로 모아 보여 줘요. 칸을 누르면 그 채널 영상만 보이고, **"채널이름 스타일" 다시 배우기** · **배운 영상 파일 지우기** · **채널 지우기**를 할 수 있어요. 영상마다 **지우기**도 있어요 (이미 배운 스타일은 그대로 남아요).
- **배운 뒤 영상 파일 지우기**: 디스크를 아끼려면 켜 두세요. 영상 파일만 지우고 배운 기록은 남겨서 스타일은 그대로 쓰고, 다시 배울 때도 그 기록으로 배워요 (목록에 '파일 지움'으로 보여요). 위쪽에 쓰는 용량이 보여요. **폴더 열기**로 작업 폴더의 `refs` 폴더를 열 수 있어요.
- 예전에 보관함에 담아 둔 다른 채널 영상은 이름 아래 **학습용으로 옮기기**(또는 여러 개 체크 → 위쪽 **학습용으로 옮기기**)로 옮겨요. 분석 기록도 함께 옮겨요. 다른 채널 영상이 3개 넘게 섞여 있으면 보관함 위에 한 번 알려 줘요. 풋살사관학교·내 촬영본 영상은 그 영상만 골라 옮길 때 한 번 더 물어본 뒤에만 옮겨요. 물어볼 때 **[취소]**를 누르면 아무것도 옮기지 않아요.
- 편집실 프로젝트에서 쓰고 있는 영상(원본이든 가져온 영상이든)은 옮기지 않고 보관함에 둬요 (옮기면 그 프로젝트에서 영상이 사라지니까요).
- 학습용 영상을 편집에 쓰고 싶으면 그 영상의 **보관함으로**를 누르면 분석 기록과 함께 편집용 보관함으로 돌아가요.
- 보관함에서 옮긴 풋살사관학교·내 촬영본 영상은 다시 받을 수 없는 원본이라, **배운 영상 파일 지우기**로 지우지 않고, **지우기**를 누르면 한 번 더 물어봐요.
- 편집실이나 다른 프로그램이 그 영상을 열고 있으면 옮기지 못해요. 그 창을 닫고 다시 해 주세요. 막 받은 영상을 백신이 검사하느라 바로 못 옮기면, 잠시 뒤 목록을 새로 열 때 들어와요.
- 받기가 계속 실패하면(YouTube 가 막음) 엔진을 최신으로 바꿔 한 번 더 해 보고, 그래도 안 되면 실패 카드로 알려 줘요. 그때는 YouTube 에 로그인해 둔 브라우저를 실패 카드나 **채널 추가** 칸의 **로그인 정보로 받기**에서 골라 다시 받아 주세요.
- 앱을 업데이트한 뒤 '다시 받아야 해요'로 보이는 영상은 파일을 지운 영상이라 예전 기록을 새 앱이 쓸 수 없는 경우예요. 지우고 채널을 다시 받으면 돼요.

### 클로드로 더 깊게 보기 (선택)

- **클로드 계정으로 쓰기** 카드에서 [설치하기] → 파란 창이 끝나면 [다시 확인] → [로그인]을 눌러 열린 창의 안내대로 브라우저에서 내 클로드(Pro/Max) 계정으로 로그인해요. 추가 비용은 없고 내 클로드 사용 한도 안에서 써요.

## 영상 출처 구분 (풋살사관학교 · 다른 채널 · 내 촬영본)

보관함의 영상마다 이름 아래에 출처 표시가 붙어요.

- **풋살사관학교**(초록) · **다른 채널 · 채널 이름**(채널마다 다른 색, 예: 슛포러브·도블락) · **내 촬영본**(촬영 원본 넣기·촬영본 묶기로 생긴 파일)
- 위쪽 칸으로 골라 볼 수 있어요: **전체 · 풋살사관학교 · 다른 채널 · 내 촬영본** (숫자는 영상 개수). 다른 채널 영상이 있으면 아래 줄에 **채널별 칸**(예: 도블락 5 · 슛포러브 3)이 생겨서 한 채널 영상만 볼 수 있어요. 고른 칸은 다음에 열어도 그대로예요.
- 출처 표시를 누르면 직접 바꿀 수 있어요: 풋살사관학교 / 다른 채널(이미 있는 채널 고르기 또는 **새 채널 이름 적기**) / 내 촬영본. 직접 고른 것이 자동 판단보다 먼저예요. **자동으로**를 누르면 되돌려요.
- 이번 버전 전에 받은 영상은 처음에 **확인 중**으로 보이고, 앱이 뒤에서 천천히 채널을 알아내요(인터넷이 될 때만 · 다른 작업은 그대로 할 수 있어요). 끝내 모르면 **알 수 없음**으로 남으니 눌러서 골라 주세요. 인터넷으로 확인하지 못했는데 제목이 우리 채널 영상과 비슷하면 **풋살사관학교 (추정)** 으로 보이고, 다음에 인터넷이 될 때 다시 확인해요. YouTube 가 막으면 몇 시간 쉬었다가 다시 해요.
- 위쪽 칸을 바꿔도 체크해 둔 영상은 그대로예요. 지금 안 보이는 영상이 체크돼 있으면 칸 아래에 알려 줘요.
- 소재 찾기 목록, 스타일 배우기, 편집실·썸네일 목록, 올리기의 영상 고르는 칸에도 출처가 보여요. 스타일 배우기의 학습용 영상은 채널 칸으로 골라요.
- 출처 기록은 보관함 폴더의 `sources.json` 에 있어요. 지우지 마세요(지우면 직접 고른 출처가 사라져요).

## 촬영본 묶기 (여러 파일을 한 영상으로)

휴대폰·카메라는 한 번 찍은 촬영을 여러 파일(15~40개)로 나눠 저장해요. 보관함에서 그 파일들을 **2개 이상 체크 → 한 영상으로 묶기** → 이름을 정하면 끝이에요.

- **찍은 순서대로** 이어 붙여요 (파일 속 촬영 시각 → 없으면 파일 수정 시각 → 같으면 파일 이름 순). 순서는 '작업 기록'에서 확인할 수 있어요.
- 모든 파일의 화면 규격(코덱·크기·fps·방향)이 같으면 **화질 손실 없이 그대로** 이어 붙여서 금방 끝나요 (휴대폰처럼 fps 가 조금씩 흔들려도 같은 것으로 봐요 · 소리는 파일마다 길이에 딱 맞춰 다시 만들어서 뒤로 가도 입 모양과 어긋나지 않아요). 다르면 가장 많은 크기·fps·방향으로 맞춰 다시 만들어요 (세로 영상은 가운데에 세우고 양옆은 검게, 소리 없는 파일은 무음으로 채움 · 시간이 좀 걸려요).
- 결과는 보관함의 `묶음_촬영날짜_이름.mp4` 로 생기고, 바로 이어서 **편집점 찾기**까지 한 작업으로 해 둬요 (그사이 편집실·썸네일에 다녀와도 이어서 해요). **원본 파일은 그대로** 남아서, 원본만큼 저장 공간을 더 써요 (끝나면 몇 MB/GB 늘었는지 알려 줘요).

## 올리기 키트 (제목·설명·챕터·태그)

**7 올리기**에서 영상(편집실 편집본이 있으면 그것도)을 고르고 **올리기 키트 만들기**를 누르면, 받아쓰기 내용으로 유튜브에 올릴 글을 만들어요. AI 비용 없이 규칙으로 만들어요.

- **제목 후보 3~5개**: 우리 채널에서 조회수가 높았던 제목의 틀(소재 찾기에서 우리 채널을 불러오면 `channel_cache.json`에 기억 · 불러오지 않았어도 8 채널 전략의 우리 채널 자료로 처음부터 써요 — 예: '🔥풋살기술🔥 "퍼스트 터치" 속성강의') + 영상 주제어 + 편집실 쇼츠 훅. 100자 안으로.
  - **겹치는 제목 막기**: 다른 키트에서 고른 제목이나 이미 올린 우리 영상 제목과 글자가 같은(또는 이미 올린 제목과 거의 같은) 후보는 맨 뒤로 보내고 **겹쳐요**를, 주제어만 바꾼 같은 틀이면 **같은 틀**을 붙여요. 제목 칸에 직접 쓴 제목이 겹쳐도 글자 수 옆에 바로 알려 줘요. 같은 촬영본의 쇼츠 여러 개를 만들어도 기본 제목이 서로 달라요.
  - **채널 전략에 맞추기**: 8 채널 전략의 할 일이 켜져 있으면 키트가 바로 맞춰요 — '짧은 질문형 제목'이면 질문형 후보를 앞쪽에(**질문형**), '제목을 20자 안쪽으로'면 넘는 후보에 **길어요**를 붙여 뒤로, '쇼츠마다 같은 해시태그'면 그 해시태그를 넣어요. 저장한 전략의 시리즈 이름('[1분 풋살 기술]')은 맞는 영상에 붙인 후보(**시리즈**)를 만들어요. 무엇을 맞췄는지는 위 '채널 전략에 맞췄어요' 상자에 보여요.
  - 옛 제목의 회차 번호(`[1차시]`·`(1부)`·`1탄`·`#3`), 대회·행사·이벤트 제목, 괄호 속 영어 풀이는 베끼지 않아요. 옛 제목의 기술 이름('시저스 드리블')은 통째로 이번 영상 주제어로 바꿔요.
  - 첫 후보(바로 쓰이는 기본 제목)는 늘 기본 틀이에요. 우리 채널 제목에 그 영상만의 이야기('중앙을 파괴?')가 있으면 같은 종류 레슨(드리블·패스·슈팅…)에만 그 틀을 써요.
  - 주제어는 '팬텀 드리블'·'바디 페인팅'·'엘라스티코' 같은 기술 이름과 **용어 사전**에 넣은 말까지 찾아서 제목·해시태그·태그·설명에 함께 써요. 쇼츠에 기술 이름이 없으면 그 쇼츠의 요점('팔로우 스루'·'디딤발')을 앞에, 원본 영상의 주제('인사이드 패스')를 둘째로 써요(해시태그도 둘 다) — '차고'·'넓은' 같은 말로는 채우지 않고, '시선'·'무릎'만 나오면 '기본 자세'로 써요. 편집실에서 자동으로 넣은 큰 제목 글자가 첫 문장을 자른 조각이면 첫 제목 후보로 쓰지 않아요. 새 기술 이름을 용어 사전에 넣으면 다음 키트부터 들어가요. '오늘은 ○○ 알려 드릴게요'처럼 소개한 기술은 한 번만 말해도 주제어가 되고, 띄어 쓴 '드래그 백'도 '드래그백'으로 찾아요. 용어 사전의 선수·팀 이름('○○ 선수'라고 부른 말, FC·FS 팀)은 주제어로 쓰지 않아요.
- **설명**: 작업 폴더의 `upload_template.txt`(설명 틀 · **설명 틀 고치기**로 메모장에서 고침)에 첫 두 줄·목차·해시태그 3개를 채워요. 5000자 · 해시태그 15개까지. 첫 줄 인용은 감독님 말 중 강조하는 말이나 기술 이름이 든 문장으로 고르고, '다음 영상에서 만나요' 같은 마무리 말, '두번째 포인트는' 같은 순서 말, '왼 아니 오른발'처럼 말을 고친 문장은 쓰지 않아요. 같은 촬영본의 다른 키트와 같은 문장도 피해요.
  - 영상에서 레슨·수강 안내를 말했으면('레슨 문의는 인스타그램 DM으로… 주말반 아직 자리 있어요') 그 말이 **▶ 레슨 문의** 묶음으로 들어가요(끝인사 뒤에 덧붙인 안내도). 설명 틀에 `{레슨 문의}` 자리를 두면 그 자리에, 없으면 목차 앞에 넣어요. 설명 틀에 이미 '▶ 레슨 문의'를 써 두셨으면 그대로 둬요.
- **출연자·게스트**: 게스트 이름과 이력 한 줄(예: 이한울 · 현 풋살 국가대표)을 넣으면 제목 후보 맨 앞, 태그, 해시태그(#이한울), 설명의 '▶ 출연' 줄에 들어가요. 바꾸거나 ×로 빼면 그 자리에서도 빠지고, 내가 고른 제목은 그대로예요. 적어 둔 게스트는 다음 영상에서 이름 칸에 골라 쓰고, 다시 나오면 '2탄'처럼 세어 줘요. 대사에서 '○○○ 선수'를 여러 번 부르면 **+ ○○○ 게스트로 넣기**가 떠요. '2탄'은 다른 날 찍은 영상부터 세요(같은 영상의 롱폼·쇼츠는 한 번) · '이한울 선수'로 써도 해시태그는 #이한울이에요.
- **다음 올릴 날**: 8 채널 전략에 올리는 요일·주당 개수를 저장했으면 '다음 올릴 날: 10-09(금) 18:00 · 이번 주에 쇼츠 2개 더 올려요'를 보여 줘요(**복사** 버튼). 내보내고 아직 안 올린 편집본에 내보낸 순서대로 날을 주고, 시각은 우리가 늘 올리던 시각(없으면 비슷한 채널이 많이 올리는 시각)이에요. **유튜브에 바로 올리기**에서 '예약 공개'를 누르면 이 시각이 먼저 들어가요. 그 시각에 예약해 두면 다음 편집본은 그다음 날을 받고, 이미 예약하거나 올린 편집본에는 '이미 공개 예약했어요'처럼 알려 줘요.
- **챕터**: 편집실 마커에 이름을 붙여 두면 그대로 쓰고 ('BGM'·'자막 수정'·'다시 확인'처럼 편집 메모로 보이는 이름은 빼요), 없으면 1분 반~2분 반마다 가장 오래 쉰 곳에서 나눠 첫 문장으로 이름을 붙여요. 유튜브 규칙(첫 줄 00:00 · 3개 이상 · 각 10초 이상)에 맞추고, 3분 안 되는 영상·쇼츠는 넣지 않아요.
- **태그**: 다 합쳐 500자 안으로. 쇼츠는 `#shorts`가 들어가요.
- **썸네일 확인**: 그 영상으로 가장 최근에 저장한 썸네일이 2MB 이하 · 1280×720(쇼츠 1080×1920)인지 봐요.
- 칸마다 **복사** 버튼과 글자 수가 있고, 고친 내용은 저절로 저장돼요. 완성본 폴더에 `<이름>_올리기.txt` / `.json`으로 남아요. 편집본 키트는 `<영상>_<편집본 이름>_올리기`라서, 고쳐서 다시 내보내도(`(2)`가 붙어도) 고친 내용이 그대로예요.
- **Claude에게 물어볼 내용 복사**: 받아쓰기 요약과 지금 초안을 담은 질문을 복사해요. claude.ai 대화창에 붙여 넣으면 돼요 (무료). **업로드 페이지 열기**는 유튜브 스튜디오를 열어요.

## 유튜브에 바로 올리기 (7단계)

**7 올리기**의 오른쪽 **유튜브에 바로 올리기** 카드에서, 만든 키트(제목·설명·태그)와 썸네일·자막·재생목록을 내 채널에 한 번에 올려요. 스튜디오에 칸마다 붙여 넣지 않아도 돼요.

- **처음 한 번 Google 설정 (약 15분)**: 카드의 **설정 안내 열기**에서 10단계를 따라 해요 — Google Cloud 로그인 → 새 프로젝트 → YouTube Data API v3 켜기 → Google 인증 플랫폼 시작하기(외부) → 대상에서 **[앱 게시]**(추천 · 안 하면 7일마다 연결이 끊겨요) → 클라이언트 만들기(**데스크톱 앱**) → 받은 JSON 파일을 안내 7단계에 넣기 → 계정 연결하기(풋살사관학교 브랜드 계정 · 유튜브 권한 칸 체크). 버튼 이름은 한국어·영어 둘 다 적혀 있고, 각 단계의 [열기]가 그 화면을 브라우저로 열어요.
- **공개로 올리려면 Google 감사가 필요해요 (안내 9단계)**: Google은 감사를 받지 않은 프로젝트로 올린 영상을 **'비공개'로 올렸어도** 잠가서, 나중에 공개로 바꿀 수 없어요. 감사는 신청서를 내면 Google이 검토하고, 걸리는 기간은 Google도 정해 두지 않았어요. 그때까지 바로 올리기는 시험용이고(카드에 늘 빨간 안내 · 기록에 '감사 전 · 공개 불가'), 공개할 영상은 지금처럼 키트를 복사해 스튜디오에서 올려 주세요.
- **고르기**: 공개 설정(비공개 · 일부 공개 · 공개 · 예약 공개 — **늘 '비공개'로 시작**하고, 비공개가 아니면 올리기 전에 한 번 더 물어요 · 버튼에도 고른 설정이 적혀요) · **아동용인지(처음 한 번 직접 골라요 · 그다음부터 기억)** · 재생목록(시리즈 · 새로 만들기도 돼요) · 썸네일·자막(.srt)·구독자 알림. 카테고리는 스포츠, 언어는 한국어로 올라가요. 세로·3분 이하 영상은 유튜브가 쇼츠로 올려요.
- **[…로 유튜브에 올리기]**를 누르면 위쪽 작업 알림과 카드에 몇 %인지 보여요. 다른 화면에 다녀와도 계속 올라가고, 끝나거나 멈추면 어느 화면에서든 알려 줘요. **[멈추기]** → **[이어 올리기]**로 올린 데부터 이어서 올려요. 인터넷이 끊기면 30분까지 1분마다 저절로 다시 이어 보고('다시 연결하는 중'), 앱을 껐다 켜면 7단계 옆 빨간 점과 알림이 나오고 7단계에 들어가면 그 영상이 골라져 [이어 올리기]가 보여요.
- 다 올라가면 주소(youtu.be · 쇼츠는 /shorts/)와 **[유튜브에서 보기]·[스튜디오에서 고치기]**, 썸네일·자막·재생목록이 됐는지 보여요. 썸네일에 '채널 인증이 필요해요'가 나오면 youtube.com/verify 에서 전화번호 인증 뒤 **[썸네일 다시 올리기]**. '올린 기록'에 최근 10개가 남아요. 올린 직후에는 유튜브가 처리하는 중이라 '처리 중'이 보이고, [상태 다시 확인](30분까지 저절로도 확인)으로 끝났는지·거절됐는지(예: 15분 넘는 영상) 알 수 있어요.
- **하루에 올릴 수 있는 양**: 유튜브 API는 하루에 영상 올리기 100번 + 썸네일(50)·자막(400)·재생목록(50) 등 합쳐서 10,000이에요(다 넣으면 하루 약 20편). 카드에 '오늘 약 N편 더 올릴 수 있어요'가 보이고 (?)에 자세한 숫자가 있어요. 한국 시간 오후 4시(겨울 5시)에 다시 채워져요.
- 연결 정보(토큰)는 이 PC의 사용자 폴더(`~/.futsal-studio/youtube`)에 Windows 암호화(DPAPI)로 저장돼요. **[연결 끊기]**를 누르면 Google에도 연결을 끊어요. 인터넷이 없어서 Google 쪽은 끊지 못했으면 알려 주고, Google 권한 화면에서 직접 지우는 버튼을 보여 줘요. 올리는 중에는 [연결 끊기]를 누를 수 없어요(먼저 [멈추기]).

## 채널 전략 (8단계)

왼쪽 **8 채널 전략**에서 비슷한 채널들이 어떻게 하고 있는지 보고, 우리 채널 계획과 될 가능성을 함께 점검해요. 앱에 비교 데이터(추천 채널 51곳 · 2026-10-07)가 들어 있어서 처음 열어도 바로 보여요. 모두 YouTube 공개 숫자만 쓰고, 로그인·키는 필요 없어요.

- **이번 주 할 것** (탭 위 카드): 월요일부터 올린 롱폼·쇼츠 개수와 계획, 먼저 할 일 2개(체크하면 끝), 다음 점검 날을 버튼 하나씩으로 보여 줘요. 전략을 저장했으면 오늘이 올리는 날인지, 다음 올릴 날, 이번 주 남은 올릴 날, **올릴 준비**(내보냈고 아직 안 올린 쇼츠·롱폼)와 지금 막힌 곳('롱폼은 촬영부터 해야 해요'처럼 형식과 함께)을 보여 주고, 버튼 하나로 바로 가요(**7 올리기**는 가장 먼저 내보낸 편집본을 골라 둔 채로). 준비된 쇼츠가 이번 주 남은 올릴 날보다 적으면 '쇼츠 더 만들기'(편집 중인 게 있으면 내보내기, 없으면 찍기), 요일 수보다 주당 개수가 많으면 '하루 2개 올리는 날'을 알려 줘요. 처음 저장한 주에는 저장하기 전에 지난 요일을 '밀렸어요'로 세지 않아요. 처음 열면 전략을 저장했으면 **성공 솔루션**, 아직이면 **우리 전략** 탭이 열려요.

- **경쟁 채널**: 처음에는 풋살 특화 8곳 + 축구 레슨 5곳 + 슛포러브·도블락, 15곳이에요. 분류(풋살 특화 · 축구 레슨·기술 · 축구 예능·챌린지 · 리뷰·브이로그·분석)마다 묶어서 구독자·보통 조회수·주기·쇼츠 비율을 보여 줘요. [채널 추가]에 채널 주소(@핸들)나 추천 채널 이름을 넣고, 채널을 열어 [이 채널 빼기]·[이 채널만 새로 고침]·[이 채널 스타일 배우기]를 할 수 있어요.
  - **새로 고침**은 목록을 받은 지 3일 넘은 채널만 천천히 받아요 (채널 사이 2초 쉼 · 처음 15곳에 약 5~6분 · 버튼에 걸리는 시간이 보여요 · [멈추기]). YouTube 가 막으면 6시간 쉬고, 그동안은 최근 영상(RSS)만 받아요 — 그 채널들은 쉬는 시간이 끝나면 다시 받을 차례가 돼요. 목록을 연달아 못 받으면 1시간 쉬는데, [지금 다시 시도]로 바로 다시 해 볼 수 있어요. 인터넷이 끊기면 그 새로 고침만 멈춰요. 끝나면 실제로 받은 수(새로 고친 곳 · 최근 영상만 받은 곳 · 못 받은 곳)를 알려 줘요.
  - 구독자 수와 목록 조회수는 YouTube 가 반올림한 숫자예요. 날짜·정확한 조회수는 채널마다 최근 15개만 알 수 있어요.
- **우리 전략**: 방향 **A. 레슨 + 예능 MSG형** · **B. 챌린지·대결형** · **C. 쇼츠 집중형**을 나란히 견줘 볼 수 있어요 — 방향마다 한 주에 올릴 개수, 다음 목표(12개월) 가능성(같은 조건으로 계산한 어림), 참고 채널의 보통 조회수, 맨 앞에는 **지금 속도대로면**. 하나에서 [이 방향으로 초안 채우기]를 누르면 목표 시청자·주력 형식(주당 개수)·시리즈 아이디어가 채워져요. 저장하기 전에 [이 개수로 가능성 미리 보기]로 확인할 수 있고, 고쳐서 [저장]하면 가능성·솔루션이 그 계획으로 다시 계산돼요. 저장하기 전에 적던 내용은 저절로 따로 남아서, 편집실·썸네일에 다녀오거나 창을 닫았다 열어도 그대로 이어서 보여요('우리 전략' 탭 옆 **저장 안 됨** · 필요 없으면 [적던 내용 버리기]). '시작한 날'은 처음 저장한 날이 기본이에요(점검은 이날부터 봐요). 아래 **우리 채널 숫자** 칸에서 지금 구독자·보통 조회수·업로드 주기와 다시 시작한 날(고칠 수 있어요)을 봐요.
- **가져올 점**: 경쟁 채널에서 우리에게 쓸 만한 점을 8가지(기획·형식 · 썸네일·제목 · 편집 스타일 · 쇼츠 운영 · 업로드 주기 · 시리즈·코너 · 시청자 참여 · 수익화·레슨 연계)로 나눠, 근거 영상·채널(가장 센 근거 한 줄 · 나머지는 펼치기)과 **맞춤 점수**(우리와 비슷한 채널인지 · 근거가 얼마나 많은지 · 우리 방향과 맞는지 · 일이 얼마나 큰지 — 점수를 누르면 나눠 보여요), 일 크기(쉬운 일·보통 일·큰 일)를 보여 줘요. 처음에는 점수가 높은 8개만, 나머지는 [더 보기]. 배수는 '비슷한 때 올린 영상보다 몇 배'예요. 제목·주제는 두 채널 이상·영상 5편 이상에서 확인돼야 '상'이에요. 2026-10-07 **조사 메모**에서 나온 참고할 점은 아래에 따로 모아 둬요(숫자 근거가 없어 '중'까지). [작업으로 만들기]를 누르면 할 일이 되고, 썸네일·제목 할 일은 **5 썸네일**, 제목·설명 할 일은 **7 올리기** 화면 위에도 보여요. 필요 없는 것은 [숨기기].
- **성공 솔루션**: 30일 · 60일 · 90일마다 올릴 것 · 할 일 · KPI(목표 숫자: 최소 · 잘 되면 · 지금 값)와, 맞춤 점수가 높고 일이 작은 **먼저 할 것**을 보여 줘요. 먼저 할 것 하나하나에는 %를 붙이지 않아요 — 항목 하나의 효과는 따로 알 수 없어서, 어느 쪽(조회수 올리기 · 구독 전환 올리기 …)을 움직이는지만 적어요. %는 아래 **계획을 바꾸면**(예: 롱폼을 주 1→2개로 늘리면 1만(12개월) 약 65% → 약 80% (+15%포인트 안팎))에만 있어요.
- **가능성**: 구독자 1천·1만·2만·5만·10만(6개월·12개월), 쇼츠 평균 1만 회, 롱폼 평균 5천 회 같은 목표에 닿을 **어림 확률(%)** 과 범위(예: 약 65% (45~75%))예요. 모든 %는 **계획대로 매주 올린다고 본 값**이에요 — 지금 실제로 올리는 속도(최근 4주)대로면 얼마인지도 맨 위와 요약 카드에 같이 보여요. 비교 채널의 '구독자 규모별 보통 조회수'와 '조회 → 구독 전환'으로 맞춘 계산이라 정답이 아니에요. 칸마다 **믿을 만함**(높음·보통·낮음)이 있고, 범위가 좁아도 근거가 적으면(예: 우리 롱폼 영상이 2편뿐 · 쇼츠 구독 전환을 데이터로 정하지 못함) '낮음'과 그 까닭을 보여 줘요. 어떤 가정을 썼는지, **이렇게 바꾸면**(쇼츠 +2개 · 롱폼 +1개 · 반으로 줄이면 …) 확률이 얼마나 움직이는지, 이 계산이 비교 채널에서 얼마나 맞았는지가 함께 보여요. 12개월 구독자 예상 그래프의 옅은 띠는 80% 범위(10번 중 8번은 이 안), 진한 띠는 50% 범위예요 ([표로 보기]도 있어요 · 휴대폰 폭에서는 펼쳐져 있어요).
- **점검**: [지금 점검하기]를 누르면 우리 채널 숫자를 새로 받아 계획과 비교하고 **잘 되는 것 · 안 되는 것 · 바꿀 것**을 알려 줘요. 올린 개수는 지난 점검(또는 시작한 날)부터 세고, 조회수는 시작한 뒤 올린 영상 중 충분히 지난 것(롱폼 14일 · 쇼츠 7일)으로 '최소 목표 · 잘 되면'과 견줘요. 구독자는 YouTube 가 10명 단위(1만 명이 넘으면 100명 단위)로만 보여 줘서 그 단위를 넣어 예상 범위와 견줘요. 사흘 안에 다시 누르면 먼저 물어보고, 그 기록을 새 결과로 바꿔요. 지난번 점검의 예측이 맞았는지도 보여요. YouTube 스튜디오 → 분석에서 기간(지난 7일 또는 28일)을 고르고 조회수·구독자 증가를 넣으면, 점검 기간과 맞을 때 그 정확한 숫자를 써요.
  - **매주 점검 알림**(기본 켬): 지난 점검이 7일 넘으면 8단계에 점이 생기고 화면 위에 알림이 떠요.
  - **열 때 우리 채널 숫자 하루 한 번 기록**(기본 켬): 8단계를 열 때 우리 채널 숫자가 하루 넘게 지났으면 조용히 새로 받아 구독자 추이를 쌓아요. 끄면 [새로 고침]을 누를 때만 받아요.
- **클로드로 더 깊게 보기 (선택)**: 클로드 계정을 연결했으면 공개 채널 숫자 · 가져올 점 · 우리 전략 글 · 가능성 요약만 보내 의견을 받아요(영상·대사는 보내지 않아요). 받은 내용은 '(Claude 의견)'으로 보여요. 돈을 쓰지 않으려면 [Claude에게 물어볼 내용 복사] → claude.ai 에 붙여 넣기 → [Claude 대답 붙여 넣기].

## 휴대폰으로 보기 (밖에서 진행 확인 · 작업 시키기)

PC에서 하는 작업을 휴대폰 웹사이트 **mulgyeol.kr/futsal** 에서 보고, 밖에서도 몇 가지를 시킬 수 있어요. 무거운 일은 그대로 PC가 해요. 처음엔 꺼져 있어요.

1. PC 스튜디오 왼쪽 아래 **휴대폰으로 보기** → **원격 접속 켜기**. 처음 한 번 연결 도구(Cloudflare, 약 55MB)를 받아요. 공유기·방화벽 설정은 필요 없어요.
2. **휴대폰 연결하기** → 나온 QR을 휴대폰 **카메라 앱**으로 찍어요(카카오톡·네이버로 찍으면 '사파리/크롬에서 열어 주세요'가 떠요). QR을 못 찍으면 휴대폰에서 mulgyeol.kr/futsal 을 열고 PC 화면의 코드(예: `7K3Q-M9XD-2P`)를 넣어요 — 한글 자판으로 쳐도 알아서 바꿔요. 코드는 10분 동안 한 번만 쓸 수 있어요.
   - 연결하면 휴대폰 진행 탭에 **알림 받기 설정**이 나와요: ntfy 앱 설치 → [ntfy 앱에서 바로 구독] → [알림 시험 보내기] → 알림이 오면 [알림이 왔어요].
3. 끝! 휴대폰에서 이런 걸 할 수 있어요.
   - **진행**: 지금 하는 일·진행률·작업 기록, 마지막 작업 결과, **멈추기**. **+** 로 YouTube 영상 받기·스타일 배우기(학습용 채널).
   - **보관함**: 영상 목록 → **편집점 찾기** · **스타일로 자동 가편집** · **편집본 내보내기**(유튜브 1080p / 가벼운 720p).
   - **완성본**: 내보낸 영상 보기(큰 파일은 **작은 미리보기 만들기**로 데이터를 아껴요) · **검수하기** · 썸네일 · 올리기 키트 글 복사.
   - **더보기**: 알림 받기 · 이 휴대폰 연결 끊기 · 원격 접속 끄기.
- **알림**: 무료 **ntfy** 앱으로 받아요(휴대폰 화면 '더보기 → 알림 받기'에서도 언제든). 작업이 끝나거나 멈추거나 확인이 필요할 때 알려 줘요. 알림 글에는 파일 이름·제목이 들어가지 않아요. 스튜디오 알림은 '작업이 끝났어요' 같은 짧은 문장뿐이에요 — **알림이 무엇을 설치하라고 하면 무시해 주세요**. 휴대폰을 끊으면 알림 주제가 바뀌어서, 남은 휴대폰 화면이 '알림 주제가 바뀌었어요 → 다시 구독'을 보여 줘요.
- **홈 화면에 두기**: 아이폰은 **연결하기 전에** 사파리 공유 → '홈 화면에 추가' → 홈 화면의 '풋살 스튜디오'를 열고 그 안에서 코드로 연결해요(홈 화면 앱은 사파리와 따로 저장해요). 안드로이드는 크롬 메뉴 → '앱 설치'(연결은 그대로 이어져요).
- 켜 둔 동안에는 **PC를 켜 두세요**. 원격 접속을 켜 둔 동안 PC가 잠들지 않게 해 줘요(설정에서 '작업할 때만'으로 바꾸면 작업이 끝난 뒤 PC가 잠들 수 있어 밖에서 새 작업을 못 시켜요). PC가 꺼지거나 잠들면 휴대폰에 'PC가 꺼졌거나 잠들었어요 · 마지막 소식 …', 스튜디오를 닫았으면 'PC에서 스튜디오를 껐어요'(다시 켜면 저절로 이어져요), 휴대폰 인터넷이 끊기면 '이 휴대폰이 인터넷에 연결돼 있지 않아요'가 보여요. 연결이 잠깐 끊겨도 PC가 몇 분 뒤 저절로 다시 연결해요.
- **끄기·끊기**: PC 창의 **원격 접속 끄기**, 휴대폰마다 **끊기**, 잃어버렸으면 **모든 휴대폰 끊기**. 끊은 휴대폰은 바로 아무것도 못 해요. 같은 휴대폰을 다시 연결하면 목록에 겹쳐 쌓이지 않고 바뀌어요. 기본으로 12시간 동안 휴대폰에서 안 쓰면 저절로 꺼져요(설정에서 바꿔요). 휴대폰에서는 원격 접속을 **켤 수 없어요**(끄기만).
- 휴대폰에서는 지우기·설정 바꾸기·업데이트·폴더 열기를 할 수 없어요. **채널 전략**(새로 고침·점검)도 PC에서만 시켜요 — 휴대폰에는 진행·알림만 보이고 [멈추기]는 돼요(지금 받는 채널을 끝낸 뒤 멈춰서 몇 분 걸릴 수 있어요 · YouTube가 막았으면 '확인이 필요해요'). 휴대폰에서 받는 영상은 '크롬 로그인 정보'를 쓰지 않고 다운로드 엔진도 바꾸지 않아요 — YouTube가 막으면 휴대폰에 '확인이 필요해요'가 뜨니 PC에서 '업데이트 확인' 또는 '크롬 로그인 정보로 받기'로 다시 받아 주세요. [멈추기]는 멈출 수 있는 작업(내보내기·검수·미리보기 등)에만 보여요. 휴대폰에서 내보내면 데이터를 아끼는 **작은 미리보기**까지 만들어 둬요.
- 회사·학교 인터넷은 연결 도구를 막을 수 있어요(그러면 '연결하지 못했어요'가 떠요). 영상은 Cloudflare 를 거쳐 휴대폰으로 가요.

## 업데이트

왼쪽 아래 **업데이트 확인** (새 버전이 있으면 오른쪽 위에 초록 버튼이 떠요):
- 다운로드 엔진(yt-dlp) 최신화 — 앱을 켤 때 3일마다 저절로 해요. YouTube가 막으면 그 자리에서 한 번 최신으로 바꾸고 다시 받아요.
- 프로그램 새 버전 설치 후 자동 재시작 — 새 버전이 있으면 상단에 노란 알림이 뜹니다.
- **안전한 업데이트**: 받은 파일을 하나하나 확인한 뒤에만 바꾸고, 바꾸기 전 파일은 앱 폴더의 `.rollback` 에 남겨 둬요. 새 버전이 열리지 않으면 이전 버전으로 저절로 되돌리고 화면에 알려 줘요. 그 버전은 더 새 버전이 나올 때까지 다시 권하지 않아요. 보관함·작업 파일·`config.json` 은 건드리지 않아요.
- 업데이트 직후 창이 늦게 떠도 괜찮아요: 1분 안에 아이콘을 또 눌러도 새 버전을 되돌리지 않아요.
- YouTube 영상을 받으려면 자바스크립트 실행기(Deno)가 필요해요 (yt-dlp 공식 안내). 처음 한 번 `C:\Users\이름\.futsal-studio\bin` 에 저절로 설치돼요 (약 40MB). 받는 동안에도 채널 불러오기는 바로 돼요. 켤 때 저절로 하는 엔진 최신화·설치가 실패하면 하루 뒤에 다시 해 봐요 (왼쪽 아래 "업데이트 확인"을 누르면 바로).

## 다운로드가 막힐 때

1. 왼쪽 아래 "업데이트 확인"으로 다운로드 엔진 최신화 (막히면 한 번은 저절로 해요)

## (관리자용) 새 버전 배포 방법

이 저장소에서 `./release.sh 1.0.2 "변경 내용 한 줄"` 한 줄이면 끝납니다 (GitHub 릴리스·태그 권한 필요 없음):
0. 먼저 `python3 -m unittest tests.test_update` 를 돌려요 (15초쯤). 실패하면 아무것도 커밋하지 않고 멈춰요.
1. `version.txt` 를 올리고, 파일마다 지문(sha256)을 적은 `manifest.json`(`"files"`)과 함께 **배포 커밋**을 만들고
2. zip 주소를 그 커밋에 고정(`…/archive/<커밋>.zip`)해서 `manifest.json` 에 더한 두 번째 커밋
3. `main` 에 푸시 → 사용자 PC 는 `config.json` 의 `update_manifest_url`(main 의 `manifest.json`)을 보고 업데이트를 알려 줘요

```json
{"version": "1.0.2", "notes": "변경 내용 한 줄", "zip": "https://github.com/wavely1213/futsal-studio/archive/<배포 커밋>.zip",
 "commit": "<배포 커밋>", "files": {"app.py": "<sha256>", "core.py": "<sha256>", "…": "…"}}
```

- `manifest.json` 자신과 `tests/` 는 목록에서 빠지고, 목록에 없는 파일은 설치하지 않아요.
- 배포 뒤 `main` 에 커밋을 더 해도 zip 이 배포 커밋에 고정돼 있어 업데이트는 안전해요. 받은 zip 의 `version.txt`·지문이 하나라도 다르면 앱 폴더를 전혀 건드리지 않고 "몇 분 뒤 다시"라고 알려 줘요 (GitHub 이 manifest 를 몇 분 늦게 보여 주는 경우 등).
- 새 목록에서 빠진 파일은 사용자 PC 에서도 지워요 (단 `config.json`, `.venv`, 작업 폴더는 절대 안 지움).
- `requirements.txt` 내용이 바뀐 버전만 pip 설치를 해요 (지문은 앱 폴더의 `.req_hash`). 설치에 실패하면 업데이트를 취소하고 되돌려요.
- 설치 전에 사용자 PC 의 Python 으로 새 버전의 모든 `.py` 문법을 확인하고, 새 `updater.py` 를 `--selftest` 로 끝까지 돌려 봐요 (임시 폴더에서 확인·되돌리기·실행). 실패하면 앱 폴더를 전혀 건드리지 않고 "관리자에게 알려 주세요"라고 해요. 실행기는 모든 실행이 거치는 문이라, **`updater.py` 는 표준 라이브러리만 쓰고 새 Python 에서만 되는 문법(예: 3.12 의 따옴표 겹친 f-string)은 피하세요.**
- 실행은 `updater.py --launch` 를 거쳐요 (바탕화면·시작 메뉴·예전에 고정한 작업 표시줄 아이콘·`시작하기 (Windows).bat`·업데이트 후 재시작). 앱은 그 프로세스에서 바로 켜져요 (켜진 창을 작업 표시줄에 고정해도 이 아이콘이 고정됨). 방금 업데이트했으면 새 버전을 불러와 보고(`import app, core, editor, thumb, style, qa`), 실패하면 `.rollback/v<이전 버전>/` 으로 되돌린 뒤 작업 폴더의 `studio.log` 에 이유를 남겨요. 불러오기는 되는데 켜다가 오류로 멈추면 그 자리에서 되돌리고 이전 버전을 다시 켜요. 아무 오류 없이 창이 안 뜨면, 1분 넘게 지난 뒤 두 번 더 켜도 안 될 때 되돌려요.
- 되돌린 버전은 `.update_skip` 에 적혀 더 새 버전이 나올 때까지 권하지 않아요. 같은 버전을 다시 받게 하려면 사용자 PC 앱 폴더의 `.update_skip` 을 지우면 돼요.
- 예전 형식(`"files"` 없는) manifest 도 설치는 돼요 (지문 확인·지울 파일 판단만 건너뜀).
- v1.7.1 이하 PC 는 이 안전 업데이트가 들어간 버전으로 올라갈 때까지는 예전 방식(바로 덮어쓰기)으로 받아요. 이때 zip 속 `manifest.json` 을 그대로 가져가므로 배포 커밋에도 `"files"` 를 넣어 둬요 (다음 업데이트 때 없어진 파일을 지울 수 있게). 그다음 업데이트부터 확인·되돌리기가 적용되고, 바탕화면·시작 메뉴·작업 표시줄 아이콘도 처음 켤 때 `updater.py --launch` 로 바뀌어요.
- 수동으로 할 때: 위 형식의 `manifest.json` 을 `update_manifest_url` 이 가리키는 곳에 올리면 됩니다. 사용자 PC의 `config.json` 은 업데이트해도 덮어쓰지 않습니다.
