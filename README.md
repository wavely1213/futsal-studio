# 풋살사관학교 스튜디오

채널 영상 받기 → 받아쓰기·편집점 분석 → 러프컷까지 한 화면에서 합니다.
본인 PC에서 실행하는 프로그램이고, 화면은 브라우저에 열립니다(인터넷에 공개되지 않음).

## 실행

| PC | 실행 파일 |
|---|---|
| Windows | `시작하기 (Windows).bat` 더블클릭 |
| Mac | `시작하기 (Mac).command` 더블클릭 (처음엔 우클릭 → 열기) |

- Python이 없으면 설치 페이지가 열립니다. 설치 후 다시 더블클릭하세요. (Windows는 "Add python.exe to PATH" 체크)
- 첫 실행은 구성요소 설치로 몇 분 걸립니다. ffmpeg는 자동으로 포함됩니다.
- 검은 창을 닫으면 프로그램이 꺼집니다.

## 화면 구성

1. **소재 찾기** — 채널 불러오기(조회수 순) → 썸네일을 눌러 고르기 → 보관함에 담기
2. **보관함** — 촬영 원본은 "촬영 원본 넣기"로 연 폴더에 넣기 → 체크 → 편집점 찾기
3. **편집점** — 대사·컷 후보·하이라이트를 시간순으로 확인 → "Claude에게 보낼 내용 복사"
4. **러프컷** — Claude가 준 컷 목록 붙여넣기 → 미리보기 확인 → 쇼츠(세로) 또는 롱폼(가로) 영상 + 프리미어·다빈치용 EDL

작업 파일은 사용자 폴더의 `풋살사관학교_작업` (Windows: `C:\Users\이름\풋살사관학교_작업`, Mac: `~/풋살사관학교_작업`)에 저장됩니다. 업데이트해도 지워지지 않습니다.

## 업데이트

왼쪽 아래 **업데이트 확인** (새 버전이 있으면 오른쪽 위에 초록 버튼이 떠요):
- 다운로드 엔진(yt-dlp) 최신화 — YouTube가 바뀌어 다운로드가 실패할 때 먼저 눌러보세요.
- 프로그램 새 버전 설치 후 자동 재시작 — 새 버전이 있으면 상단에 노란 알림이 뜹니다.

## 다운로드가 막힐 때

1. 왼쪽 아래 "업데이트 확인"으로 다운로드 엔진 최신화
2. 크롬에서 YouTube 로그인 → 소재 찾기의 "다운로드가 계속 실패하나요?" → "크롬 로그인 정보로 받기" 체크 후 다시 담기 (본인 PC 안에서만 쓰입니다)
3. 그래도 안 되면 YouTube Studio에서 직접 다운로드하거나 Google 테이크아웃으로 받아 영상 폴더에 넣기

## (관리자용) 새 버전 배포 방법

1. `version.txt` 숫자를 올립니다 (예: 1.0.0 → 1.0.1)
2. 폴더째 zip으로 묶어 업로드합니다 (`.venv` 폴더 제외)
3. `config.json` 의 `update_manifest_url` 이 가리키는 곳에 아래 `manifest.json` 을 올립니다

```json
{"version": "1.0.1", "notes": "변경 내용 한 줄", "zip": "https://.../futsal-studio-1.0.1.zip"}
```

사용자 PC의 `config.json` 은 업데이트해도 덮어쓰지 않습니다.

이 저장소에서는 `./release.sh 1.0.2 "변경 내용"` 한 줄로 위 과정을 자동 처리합니다
(version.txt·manifest.json 갱신 → 커밋 → 태그 → 푸시, 배포 zip은 GitHub 태그 압축본을 그대로 사용).
