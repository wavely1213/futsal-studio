# 풋살사관학교 스튜디오

채널 영상 받기 → 받아쓰기·편집점 분석 → 러프컷까지 한 화면에서 합니다.
본인 PC에서 실행하는 프로그램이고, 화면은 브라우저에 열립니다(인터넷에 공개되지 않음).

## 설치와 실행

| PC | 처음 한 번 | 그다음부터 |
|---|---|---|
| Windows | `시작하기 (Windows).bat` 더블클릭 | 바탕화면의 **풋살사관학교 스튜디오** 아이콘 |
| Mac | `시작하기 (Mac).command` 더블클릭 (처음엔 우클릭 → 열기) | 응용 프로그램(`~/Applications`)의 **풋살사관학교 스튜디오** |

- 브라우저가 아니라 **전용 앱 창**으로 열립니다. 검은 창은 처음 설치할 때만 보입니다.
- Python이 없으면 설치 페이지가 열립니다. 설치 후 다시 더블클릭하세요. (Windows는 "Add python.exe to PATH" 체크)
- 첫 실행은 구성요소 설치로 몇 분 걸립니다. ffmpeg는 자동으로 포함됩니다.
- 앱 창을 닫으면 프로그램도 종료됩니다.
- 문제가 생기면 작업 폴더의 `studio.log` 를 보내주세요.

## 화면 구성

1. **소재 찾기** — 채널 불러오기(조회수 순) → 썸네일을 눌러 고르기 → 보관함에 담기
2. **보관함** — 촬영 원본은 "촬영 원본 넣기"로 연 폴더에 넣기 → 체크 → 편집점 찾기
   - 아래 **용어 사전**에 풋살 용어·이름(피벗·픽소·최경진 감독…)을 넣어 두면 받아쓰기가 더 정확해져요. 자꾸 틀리게 나오는 말은 '틀리게 나온 말 → 바른 말'로 넣으면 고쳐 줘요 (예: 피버 → 피벗). **저장**을 누르면 다음 편집점 찾기부터 적용돼요.
3. **편집점** — 대사·컷 후보·하이라이트를 시간순으로 확인 → "Claude에게 보낼 내용 복사"
4. **러프컷** — Claude가 준 컷 목록 붙여넣기 → 미리보기 확인 → 쇼츠(세로) 또는 롱폼(가로) 영상 + 프리미어·다빈치용 EDL

작업 파일은 사용자 폴더의 `풋살사관학교_작업` (Windows: `C:\Users\이름\풋살사관학교_작업`, Mac: `~/풋살사관학교_작업`)에 저장됩니다. 업데이트해도 지워지지 않습니다.

## 편집실 (v1.7.0 · 프리미어식 편집기)

보관함에서 **편집실 열기** → 프리미어 프로 같은 화면에서 편집합니다. 단축키는 프리미어와 같아요 (화면에서 ⌨).

- **트랙**: 영상 V1~V3 · 소리 A1~A3 (추가 가능). 트랙마다 잠금·음소거·솔로·숨기기·높이·대상 지정
- **가져오기**: 다른 영상·음악·이미지를 버튼/끌어다 놓기/보관함에서. 소스 모니터에서 I/O 표시 후 삽입( , ) · 덮어쓰기( . ), 정지 화면, 마커(M)
- **도구**: V 선택 · A 앞쪽 트랙 선택 · B 잔물결 · N 롤 · R 속도 늘이기 · C 자르기 · Y 슬립 · U 슬라이드 · H 손 · Z 확대
- **편집**: Ctrl+K 자르기, Shift+Delete 잔물결 삭제, Q/W 잔물결 다듬기, ; 들어내기 · ' 추출, S 스냅, Alt+끌기 복제, Ctrl+C/V, 속성 붙여넣기
- **효과 컨트롤**: 위치·크기·회전·불투명도·볼륨 키프레임(직선/부드럽게), 볼륨 고무줄
- **장면 전환**: 디졸브 · 검정/흰색 페이드 · 닦아내기 · 밀어내기 · 소리 크로스페이드 (Ctrl+D)
- **속도**: 0.25~4배, 거꾸로 재생 (Ctrl+R) · **색**: 노출·대비·채도·색온도 등 간단 보정
- **소리**: 클립 게인·페이드·오디오 믹서와 레벨 미터, 말할 때 배경음 자동 줄이기, 목소리 보정, 소리 크기 맞추기(LUFS)
- **그래픽**: 제목, 하단 이름 자막 · 구독 버튼 · 강조 팝 텍스트 등 프리셋
- **내보내기**: 유튜브 1080p · 쇼츠 1080×1920 · 고화질 프리셋, 30/60fps, 표시한 구간만, 그래픽카드로 빠르게, 진행률·남은 시간·멈추기, 프리미어 XML · 자막 SRT
- **내보낸 뒤 자동 검수**: 검은 화면 · 멈춘 화면 · 소리 끊김 · 소리 크기 · 쇼츠 규격을 확인해 점수로 알려줘요 (항목을 누르면 그 시간으로 이동)
- **안전**: 작업 기록 패널, 자동 저장, 5분마다 백업(10개) 되살리기
- **스타일로 자동 편집**: '스타일 배우기'에서 배운 스타일대로 새 가편집을 만들어요

### 1차 가편집 (자동)
보관함에서 **편집점 찾기**가 끝나면 바로 가편집까지 만들어 둡니다 (PC 안에서 계산, 비용 없음).
- **롱폼 가편집**: 추임새("아", "자", 말 사이에 홀로 나온 "음"·"어")·같은 말 반복·긴 무음을 잘라낸 가로 편집본
- **자막**: 받아쓴 단어 시각으로 읽기 좋게 나눠요. 세로 영상은 한 줄(12글자·2초까지), 가로 영상은 두 줄까지(22글자·3.5초까지). 노래방 효과는 내보낸 영상에서 말하는 순간에 맞춰 채워져요
- **쇼츠 1~3**: 강조 표현("꿀팁", "중요"…)·소리 커지는 구간으로 고른 세로 편집본. 위에 제목, 아래 자막, 위아래 검정 박스

### 쇼츠 화면 구성 (속성 → 화면 구성)
- **풀샷 자르기**: 세로 화면에 꽉 차게 자르기 (클립별 좌우 위치)
- **가로 맞춤+박스**: 가로 영상을 가운데, 위아래는 박스 (색 변경 가능)
- **블러 배경**: 위아래를 같은 영상을 흐리게 깔기
- **원본 아래/위 자르기**: 원본에 예전 자막·로고가 박혀 있으면 잘라내서 가리기
- **템플릿**: 위아래 검정 박스 · 위아래 흰 박스 · 블러 배경 · 꽉 채우기
- **도형**: 사각형 · 제목 띠 · 하단 띠 · 둥근 라벨 (색·진하기·위치·크기·둥글기·시간)

### 컷 편집
- 자막 목록의 **✂** : 그 대사 구간을 잘라내기
- **I / O** 로 구간 표시 → **'** 로 잘라내기, **Ctrl+K** 재생 위치에서 자르기, **C** 자르기 도구

단축키는 프리미어와 같습니다: Space 재생, J/K/L, ←/→ 1프레임, ↑/↓ 편집점, C 자르기, V 선택, Ctrl+K 자르기, Delete 삭제, T 타이틀, Ctrl+Z 되돌리기.

**내보내기**: 영상(mp4, 자막·효과 입힘) · 프리미어 XML(프리미어에서 파일 → 가져오기) · 자막 SRT.
자막 글꼴은 Pretendard(OFL 라이선스, `fonts/LICENSE.txt`)를 함께 넣어 어느 PC에서나 같게 나옵니다.

## 썸네일 (v1.6.0 · 포토샵식 편집기)

스튜디오의 **썸네일** 메뉴, 또는 편집실 위쪽 **썸네일 만들기**.

- **롱폼 / 쇼츠 따로**: 롱폼은 1280×720(16:9), 쇼츠는 1080×1920(9:16) 캔버스로 만들어요. 자동 제작도 형식별 템플릿(롱폼 7종 · 쇼츠 5종)이 따로 있어요.
- **영상에 박힌 옛 자막 가리기**: 장면 아래쪽을 잘라 배경에 옛 자막이 안 보이게 (이미지 속성 › 원본 자르기에서 위·아래·좌우 조절)
- **얼굴·표정으로 장면 고르기**: 얼굴이 크고 또렷하게 웃거나 놀란 장면을 먼저 골라 자동 제작에 써요 (하이라이트·대사 핵심어 순간도 살펴보고, 고른 장면 앞뒤 0.4초 안에서 표정이 가장 좋은 순간으로). 영상 장면 줄에 😆 웃음 · 😮 놀람 · 얼굴 크기(%) 표시, **시간 순 / 표정 좋은 순** 정렬. 얼굴·표정 모델(ONNX 모델 모음, 약 36MB)은 처음 한 번 내려받고, 인터넷이 안 되면 예전 방식(선명도·밝기)으로 골라요
- **글자별 편집**: 한 글자 레이어 안에서 고른 글자만 색·크기·글꼴·테두리 바꾸기 (글자칸이나 글자 칩을 드래그해서 고르기), **문자 패널** 창
- **레이어 스타일 창** (레이어 두 번 클릭): 혼합 옵션·획·드롭 섀도·3D 입체(돌출)·외부 광선·색상 오버레이·레이어 마스크(한쪽으로 서서히 사라지기)·그라데이션·글자 뒤 상자·스타일 프리셋 12종
- **변형**: 8방향 손잡이, Ctrl+T 자유 변형, Ctrl+위/아래 손잡이로 기울이기, 끄는 동안 W·H(px)·%·각도·기울기 수치 표시, X·Y·W·H·각도 숫자 입력(이름을 좌우로 끌어 미세 조절), 스마트 안내선(캔버스·다른 레이어에 붙음)
- **레이어 패널**: 끌어서 순서 바꾸기, Shift/Ctrl+클릭 여러 개, 이름 두 번 클릭 → 이름 바꾸기
- 복사·붙여넣기(이미지 붙여넣기·끌어다 놓기 포함), 전체 선택, 맞춤·간격 맞추기, 오른쪽 클릭 메뉴(겹친 레이어 고르기), 확대·축소·손 도구, 스포이드, 혼합 모드 15종, 작업 내역
- **누끼**: 고품질(BiRefNet) / 빠르게. 흰 스티커 테두리·그림자, 🖌 B 되살리기 · ⌫ E 지우개(경도 조절)
- **저장**: JPG(2MB 이하 자동 맞춤) 또는 PNG → 완성본 폴더

단축키는 포토샵과 같아요 (화면에서 **F1**): V 이동 · T 문자 · U 도형 · I 스포이드 · B/E 브러시·지우개 · H/Space 손 · Ctrl+T 자유 변형 · Ctrl+J 복제 · Ctrl+C/X/V · Ctrl+A/D · Ctrl+[ ] 순서 · Alt+끌기 복제 · 1~0 불투명도 · Ctrl+0/1 화면 맞춤/100%

## 스타일 배우기 (v1.7.0~)

잘 나가는 유튜버의 편집 스타일을 배워서 자동 가편집에 그대로 써요. (AI 사용료 없음 · 내 PC에서 분석)

1. **소재 찾기** 위쪽 칸에 따라 하고 싶은 유튜버 채널 주소(예: `https://www.youtube.com/@채널이름`, `@채널이름`)나 영상 주소를 넣고 **채널 불러오기** → 영상 2~3개를 **보관함에 담기**
2. **스타일 배우기**에서 그 영상들을 고르고 이름을 붙여 **스타일 배우기**
3. 배운 것: 컷 길이(몇 초마다 화면이 바뀌는지) · 확대 컷(펀치인) 빈도와 배율 · 말 사이 공백을 얼마나 자르는지 · 자막 위치(위/가운데/아래)와 주 색 · 소리 크기(LUFS) · 말 빠르기(편집점 찾기를 해 둔 영상이면)
4. **편집실**에서 **스타일로 자동 편집**을 고르면 그 스타일대로 새 가편집 시퀀스를 만들어요 (내가 만든 시퀀스는 그대로 둬요)

## 촬영본 묶기 (여러 파일을 한 영상으로)

휴대폰·카메라는 한 번 찍은 촬영을 여러 파일(15~40개)로 나눠 저장해요. 보관함에서 그 파일들을 **2개 이상 체크 → 한 영상으로 묶기** → 이름을 정하면 끝이에요.

- **찍은 순서대로** 이어 붙여요 (파일 속 촬영 시각 → 없으면 파일 수정 시각 → 같으면 파일 이름 순). 순서는 '작업 기록'에서 확인할 수 있어요.
- 모든 파일의 화면 규격(코덱·크기·fps·방향)이 같으면 **화질 손실 없이 그대로** 이어 붙여서 금방 끝나요 (휴대폰처럼 fps 가 조금씩 흔들려도 같은 것으로 봐요 · 소리는 파일마다 길이에 딱 맞춰 다시 만들어서 뒤로 가도 입 모양과 어긋나지 않아요). 다르면 가장 많은 크기·fps·방향으로 맞춰 다시 만들어요 (세로 영상은 가운데에 세우고 양옆은 검게, 소리 없는 파일은 무음으로 채움 · 시간이 좀 걸려요).
- 결과는 보관함의 `묶음_촬영날짜_이름.mp4` 로 생기고, 바로 이어서 **편집점 찾기**까지 한 작업으로 해 둬요 (그사이 편집실·썸네일에 다녀와도 이어서 해요). **원본 파일은 그대로** 남아서, 원본만큼 저장 공간을 더 써요 (끝나면 몇 MB/GB 늘었는지 알려 줘요).

## 올리기 키트 (제목·설명·챕터·태그)

**7 올리기**에서 영상(편집실 편집본이 있으면 그것도)을 고르고 **올리기 키트 만들기**를 누르면, 받아쓰기 내용으로 유튜브에 올릴 글을 만들어요. AI 비용 없이 규칙으로 만들어요.

- **제목 후보 3~5개**: 우리 채널에서 조회수가 높았던 제목의 틀(소재 찾기에서 우리 채널을 불러오면 `channel_cache.json`에 기억) + 영상 주제어 + 편집실 쇼츠 훅. 100자 안으로.
- **설명**: 작업 폴더의 `upload_template.txt`(설명 틀 · **설명 틀 고치기**로 메모장에서 고침)에 첫 두 줄·목차·해시태그 3개를 채워요. 5000자 · 해시태그 15개까지.
- **챕터**: 편집실 마커에 이름을 붙여 두면 그대로 쓰고 ('BGM'·'자막 수정'·'다시 확인'처럼 편집 메모로 보이는 이름은 빼요), 없으면 1분 반~2분 반마다 가장 오래 쉰 곳에서 나눠 첫 문장으로 이름을 붙여요. 유튜브 규칙(첫 줄 00:00 · 3개 이상 · 각 10초 이상)에 맞추고, 3분 안 되는 영상·쇼츠는 넣지 않아요.
- **태그**: 다 합쳐 500자 안으로. 쇼츠는 `#shorts`가 들어가요.
- **썸네일 확인**: 그 영상으로 가장 최근에 저장한 썸네일이 2MB 이하 · 1280×720(쇼츠 1080×1920)인지 봐요.

## (관리자용) 새 버전 배포 방법

이 저장소에서 `./release.sh 1.0.2 "변경 내용 한 줄"` 한 줄이면 끝납니다 (GitHub 릴리스·태그 권한 필요 없음):
0. 먼저 `python3 -m unittest tests.test_update` 를 돌려요 (15초쯤). 실패하면 아무것도 커밋하지 않고 멈춰요.
1. `version.txt` 를 올리고, 파일마다 지문(sha256)을 적은 `manifest.json`(`"files"`)과 함께 **배포 커밋**을 만들고
2. zip 주소를 그 커밋에 고정(`…/archive/<커밋>.zip`)해서 `manifest.json` 에 더한 두 번째 커밋
3. `main` 에 푸시 → 사용자 PC 는 `config.json` 의 `update_manifest_url`(main 의 `manifest.json`)을 보고 업데이트를 알려 줘요

```json
{"version": "1.0.2", "notes": "변경 내용 한 줄", "zip": "https://github.com/wavely1213/futsal-studio/archive/<배포 커밋>.zip",
 "commit": "<배포 커밋>", "files": {"app.py": "<sha256>", "core.py": "<sha256>", "…": "…"}}
```

- `manifest.json` 자신과 `tests/` 는 목록에서 빠지고, 목록에 없는 파일은 설치하지 않아요.
- 배포 뒤 `main` 에 커밋을 더 해도 zip 이 배포 커밋에 고정돼 있어 업데이트는 안전해요. 받은 zip 의 `version.txt`·지문이 하나라도 다르면 앱 폴더를 전혀 건드리지 않고 "몇 분 뒤 다시"라고 알려 줘요 (GitHub 이 manifest 를 몇 분 늦게 보여 주는 경우 등).
- 새 목록에서 빠진 파일은 사용자 PC 에서도 지워요 (단 `config.json`, `.venv`, 작업 폴더는 절대 안 지움).
- `requirements.txt` 내용이 바뀐 버전만 pip 설치를 해요 (지문은 앱 폴더의 `.req_hash`). 설치에 실패하면 업데이트를 취소하고 되돌려요.
- 설치 전에 사용자 PC 의 Python 으로 새 버전의 모든 `.py` 문법을 확인하고, 새 `updater.py` 를 `--selftest` 로 끝까지 돌려 봐요 (임시 폴더에서 확인·되돌리기·실행). 실패하면 앱 폴더를 전혀 건드리지 않고 "관리자에게 알려 주세요"라고 해요. 실행기는 모든 실행이 거치는 문이라, **`updater.py` 는 표준 라이브러리만 쓰고 새 Python 에서만 되는 문법(예: 3.12 의 따옴표 겹친 f-string)은 피하세요.**
- 실행은 `updater.py --launch` 를 거쳐요 (바탕화면·시작 메뉴·예전에 고정한 작업 표시줄 아이콘·`시작하기 (Windows).bat`·업데이트 후 재시작). 앱은 그 프로세스에서 바로 켜져요 (켜진 창을 작업 표시줄에 고정해도 이 아이콘이 고정됨). 방금 업데이트했으면 새 버전을 불러와 보고(`import app, core, editor, thumb, style, qa`), 실패하면 `.rollback/v<이전 버전>/` 으로 되돌린 뒤 작업 폴더의 `studio.log` 에 이유를 남겨요. 불러오기는 되는데 켜다가 오류로 멈추면 그 자리에서 되돌리고 이전 버전을 다시 켜요. 아무 오류 없이 창이 안 뜨면, 1분 넘게 지난 뒤 두 번 더 켜도 안 될 때 되돌려요.
- 되돌린 버전은 `.update_skip` 에 적혀 더 새 버전이 나올 때까지 권하지 않아요. 같은 버전을 다시 받게 하려면 사용자 PC 앱 폴더의 `.update_skip` 을 지우면 돼요.
- 예전 형식(`"files"` 없는) manifest 도 설치는 돼요 (지문 확인·지울 파일 판단만 건너뜀).
- v1.7.1 이하 PC 는 이 안전 업데이트가 들어간 버전으로 올라갈 때까지는 예전 방식(바로 덮어쓰기)으로 받아요. 이때 zip 속 `manifest.json` 을 그대로 가져가므로 배포 커밋에도 `"files"` 를 넣어 둬요 (다음 업데이트 때 없어진 파일을 지울 수 있게). 그다음 업데이트부터 확인·되돌리기가 적용되고, 바탕화면·시작 메뉴·작업 표시줄 아이콘도 처음 켤 때 `updater.py --launch` 로 바뀌어요.
- 수동으로 할 때: 위 형식의 `manifest.json` 을 `update_manifest_url` 이 가리키는 곳에 올리면 됩니다. 사용자 PC의 `config.json` 은 업데이트해도 덮어쓰지 않습니다.
